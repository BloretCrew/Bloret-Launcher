# 38. Teddy Totems

```

├── assets/
│   └── minecraft/
│       ├── lang/

│       │   ├── de_de.json     # 德语（德国）
```

## 包定位

Teddy Totems 是一个趣味性的外观替换资源包，由 JuniorWMG 制作。它将游戏中的 **不死图腾 (Totem of Undying)** 替换为可爱的**泰迪熊 (Teddy)** 外观。当玩家手持不死图腾时，物品模型会变成一只泰迪熊的样子，使用图腾触发时也显示泰迪熊图标。

包名中的 `§l` 是Minecraft颜色代码，表示加粗样式。命名上使用了有趣的玩具主题，将死亡保护的严肃道具变成了可爱的玩具熊，体现了资源包的趣味性定位。

## 关键文件说明

**pack.mcmeta:**
```json
{
  "pack": {
    "description": "§gTeddy Totems.\n§7By §bJuniorWMG.",
    "pack_format": 8,
    "supported_formats": [8, 255],
    "min_format": 8,
    "max_format": 255
  }
}
```

描述中使用了金色(§g)和浅蓝色(§b)来美化作/包名文字。pack_format 为8（对应Minecraft 1.18-1.20.4），但 `supported_formats` 从8到255，覆盖范围极广。这种极端的兼容性设置是因为该包只涉及物品模型和语言文件，这些内容在多个版本之间基本兼容。

**语言文件（en_us.json）：**
```json
{
  "item.minecraft.totem_of_undying": "Teddy"
}
```

这个语言文件非常简单，只做了一件事——将不死图腾的物品名称改为 "Teddy"。这是一个巧妙的配合：当玩家拿起泰迪熊外观的图腾时，物品名称也会相应地变为 "Teddy"。

其他语言文件（de_at、de_de、en_gb）的内容与 en_us 相同或类似，确保在不同语言下都能显示正确的名称。

**模型文件（totem.json / totem_of_undying.json）：**
两个模型文件内容相同，都指向了 `item/teddy_totem` 纹理。这是因为不同版本的Minecraft对不死图腾的物品ID有所变化，两个文件确保了兼容性。模型使用 Blockbench 制作，包含：

- 身体 (Body)：圆润的泰迪熊身体
- 头部 (Head)：带有两只圆耳朵的熊头
- 耳朵 (Ear1 × 2)：两只半球形小耳朵
- 鼻子 (Nose)：小圆鼻头
- 嘴部 (Mouth)：微笑表情
- 眼睛 (Eye × 2)：两只黑色小眼睛
- 手臂 (Arm × 2)：短小的熊手臂
- 尾巴 (Tail)：小圆尾巴
- 腿 (Leg × 2)：两条短腿
- 爪子 (paw × 2)：脚掌

模型在不同视角下的显示配置（display）：
- 第三人称：缩放0.5，旋转180度
- 第一人称：缩放0.5，旋转-47度，Y轴偏移3.75
- 地面展示：缩放0.5，Y轴偏移1.75
- GUI：缩放0.8，旋转-44度
- 头部（作为饰品）：旋转180度，Y轴偏移14.5

**纹理文件（teddy_totem.png）：**
一个16x16（默认纹理尺寸）的泰迪熊纹理图，采用经典的棕色泰迪熊配色。与普通的不死图腾纹理完全不同，替代为可爱的玩具熊形象。

## 资源内容结构

本包的内容非常精简，分为三个部分：

1. **模型**：用Blockbench制作的3D泰迪熊模型，替代默认的不死图腾扁平2D图标
2. **纹理**：16x16的自定义泰迪熊纹理贴图
3. **语言**：将物品名称改为"Teddy"，与外观主题一致

## 技术特点

1. **Blockbench制作**：模型使用Blockbench（知名的Minecraft模型制作工具）制作，品质有保障

2. **完整的3D模型**：不死图腾默认是一个扁平的2D图标，本包将其替换为完整的3D泰迪熊模型，多个视角（第一人称、第三人称、GUI、地面、头部饰品）都有对应的显示配置

3. **兼容性良好**：虽然pack_format为8，但通过 `supported_formats: [8, 255]` 兼容所有后续版本

4. **名称替换**：通过语言文件将物品名称从 "Totem of Undying" 改为 "Teddy"，保持主题统一

5. **双重模型文件**：同时提供了 `totem.json` 和 `totem_of_undying.json` 两个模型定义，确保在不同Minecraft版本下都能正确显示

## 结论

Teddy Totems 是一个典型的趣味性外观替换资源包。它没有技术上的创新突破，不追求视觉画质的提升，也不增加任何功能——它的目的很简单，就是让不死图腾看起来更加可爱有趣。

将死亡保护的严肃道具变成一只萌萌的泰迪熊，这种反差带来了独特的幽默感。当玩家在生死关头触发图腾时，屏幕上弹出的不是庄重的图腾图标，而是一只小熊，这无疑会给游戏增添一些轻松愉快的氛围。

对于喜欢Minecraft的趣味模组和资源包的玩家来说，这是一个值得尝试的小品级资源包。它的体积小、安装简单、不影响游戏性能，但能带来一份额外的欢乐。尤其适合那些在多人服务器中喜欢展示个性的玩家。
