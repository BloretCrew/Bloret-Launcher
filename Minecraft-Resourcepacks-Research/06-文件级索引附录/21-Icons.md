### 21. `Icons v.1.13.3` 文件索引

**包类型**: GUI 图标增强与信息可视化
**文件规模**: 约 2,320 个文件，85 个目录
**特点**: 为进度、工具提示、聊天、菜单、统计等界面添加丰富的图标装饰，支持 RespackOpts 配置，兼容 Bare Bones 风格

#### 根目录
| 路径 | 功能 |
|---|---|
| `pack.mcmeta` | 资源包元数据文件 |
| `pack.png` | 资源包封面图标 |
| `readme.md` | 说明文档（Markdown 格式） |
| `readme.txt` | 说明文档（纯文本格式） |
| `respackopts.json5` | RespackOpts 配置文件（运行时选项） |
| `1.20.11-26.1/` | 旧版本兼容覆盖层 |

#### 关键目录
| 路径 | 功能 |
|---|---|
| `assets/icons/textures/advancement/` | 进度图标（含 story / adventure / nether / end / husbandry 5 个子类） |
| `assets/icons/textures/chat/` | 聊天栏图标装饰 |
| `assets/icons/textures/gui/` | GUI 界面图标 |
| `assets/icons/textures/menu/` | 菜单界面图标（含资源包选择框等） |
| `assets/icons/textures/splash/` | 闪屏文本图标 |
| `assets/icons/textures/statistic/` | 统计界面图标 |
| `assets/icons/textures/toast/` | 通知弹窗图标 |
| `assets/icons/textures/tooltip/` | 工具提示图标（含 bee / firework / info / magic / map / music / smithing / tropical_fish / banner_pattern 等子类） |
| `assets/icons/textures/respackopts/` | RespackOpts 专用纹理 |
| `assets/barebones_icons/textures/` | Bare Bones 风格兼容图标（chat / menu / tooltip） |
| `assets/apothic_enchanting/lang/` | Apothic Enchanting 模组多语言文件（100+ 语言 JSON） |
| `assets/apothic_enchanting/lang_rpo/` | Apothic Enchanting RespackOpts 语言覆盖 |
