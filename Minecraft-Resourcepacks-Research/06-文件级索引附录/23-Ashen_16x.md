### 23. `Ashen_16x` 文件索引

**包类型**: 16x 灰烬风格完整材质包
**文件规模**: 约 4,365 个文件，202 个目录
**特点**: 低分辨率灰暗风格材质包，支持 OptiFine CIT/CTM/Colormap、Polytone 颜色映射、光标扩展、实体特性等，含多版本 overlay 覆盖层

#### 根目录
| 路径 | 功能 |
|---|---|
| `pack.mcmeta` | 资源包元数据文件 |
| `pack.png` | 资源包封面图标 |
| `readme.txt` | 说明文档 |
| `paintings.txt` | 画作纹理说明文档 |
| `overlay_22-43/` ~ `overlay_22-83/` | 多版本兼容覆盖层（4 个版本目录） |

#### 关键目录
| 路径 | 功能 |
|---|---|
| `assets/minecraft/blockstates/` | 方块状态定义（大量方块 JSON） |
| `assets/minecraft/models/block/` | 方块模型定义 |
| `assets/minecraft/models/item/` | 物品模型定义 |
| `assets/minecraft/items/` | 物品定义（1.21+ 格式） |
| `assets/minecraft/lang/` | 语言文件 |
| `assets/minecraft/textures/block/` | 16x 方块纹理（大量 PNG） |
| `assets/minecraft/textures/entity/` | 实体纹理（含 70+ 生物及装备子目录） |
| `assets/minecraft/textures/entity/equipment/` | 装备纹理（盔甲、鞍具、翅膀等） |
| `assets/minecraft/textures/colormap/` | 颜色映射纹理 |
| `assets/minecraft/optifine/cit/` | 自定义物品纹理（CIT）：斧头、面包、盾牌、剑、蛋、地图等 |
| `assets/minecraft/optifine/colormap/custom/` | 自定义颜色映射 |
| `assets/minecraft/optifine/ctm/` | 连接纹理（砖块、火焰等） |
| `assets/ashen/polytone/colormaps/` | Polytone 模组自定义颜色映射 |
| `assets/cursors_extended/textures/gui/sprites/cursors/` | 光标扩展模组自定义光标纹理 |
| `assets/entity_features/textures/gui/` | 实体特性模组 GUI 纹理 |
