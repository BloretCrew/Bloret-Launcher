### 20. `Faithful 32x - 1.21.8` 文件索引

**包类型**: 高清忠实材质包（32x 分辨率）
**文件规模**: 约 9,360 个文件，430 个目录
**许可证**: 含 LICENSE.txt
**特点**: 将原版 16x 纹理提升至 32x 分辨率，保持原版风格，支持 OptiFine CTM、Forge/NeoForge/Fabric 模组兼容

#### 根目录
| 路径 | 功能 |
|---|---|
| `pack.mcmeta` | 资源包元数据文件 |
| `pack.png` | 资源包封面图标 |
| `LICENSE.txt` | 许可证文件 |

#### 关键目录
| 路径 | 功能 |
|---|---|
| `assets/minecraft/models/item/` | 物品模型定义（如 `redstone_torch.json`） |
| `assets/minecraft/optifine/ctm/` | OptiFine 连接纹理（CTM）配置 |
| `assets/minecraft/optifine/ctm/glass/` | 玻璃 CTM（含 20 种颜色子目录，每种 47 张拼接纹理 + properties） |
| `assets/minecraft/optifine/ctm/bookshelf/` | 书架 CTM 纹理 |
| `assets/minecraft/optifine/ctm/sandstone/` | 砂岩 CTM 纹理 |
| `assets/minecraft/optifine/ctm/red_sandstone/` | 红砂岩 CTM 纹理 |
| `assets/minecraft/optifine/textures/` | OptiFine 专用纹理 |
| `assets/minecraft/textures/block/` | 32x 方块纹理（数百个 PNG） |
| `assets/minecraft/textures/entity/` | 32x 实体纹理（含 70+ 生物子目录） |
| `assets/minecraft/textures/entity/equipment/` | 装备纹理（盔甲、鞍具、翅膀等） |
| `assets/forge/textures/` | Forge 模组兼容纹理（GUI 图标、流体桶遮罩） |
| `assets/neoforge/textures/` | NeoForge 模组兼容纹理 |
| `assets/fabric/textures/gui/` | Fabric 模组 GUI 纹理 |
