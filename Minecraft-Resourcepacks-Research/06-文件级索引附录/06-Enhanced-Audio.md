# 06. Enhanced Audio r7 文件索引

> 资源包全名：`Enhanced Audio r7`
> 文件总数：666 个
> 类型：音频资源包，替换/增强原版环境音、方块音效、实体音效等

---

### 根目录

| 路径 | 功能 |
|---|---|
| `pack.mcmeta` | 资源包元数据，定义包格式版本与描述 |
| `pack.png` | 资源包封面图标 |
| `assets/` | 资源包主资产目录 |

---

### 关键目录

| 路径 | 功能 |
|---|---|
| `assets/minecraft/sounds/` | 所有替换音效的根目录 |
| `assets/minecraft/sounds/ambient/cave/` | 洞穴环境音效（cave1~cave23.ogg，共23个） |
| `assets/minecraft/sounds/ambient/underwater/` | 水下环境音效（进入/退出/循环） |
| `assets/minecraft/sounds/ambient/underwater/additions/` | 水下新增音效（动物声、鲸鱼声、气泡声等） |
| `assets/minecraft/sounds/ambient/weather/` | 天气音效（下雨、雷击影响音） |
| `assets/minecraft/sounds/block/` | 方块交互音效（约20+子目录：桶、高炉、酿造台、营火、箱子等） |
| `assets/minecraft/sounds/damage/` | 伤害音效（坠落类型、血腥效果） |
| `assets/minecraft/sounds/entity/player/` | 玩家音效（攻击、进食、受伤） |
| `assets/minecraft/sounds/entity/fish/` | 鱼类实体音效 |
| `assets/minecraft/sounds/fire/` | 火焰音效 |
| `assets/minecraft/sounds/item/` | 物品音效（铁砧、斧头、破坏、桶、鞘翅等） |
| `assets/minecraft/sounds/liquid/` | 液体音效 |
| `assets/minecraft/sounds/mob/` | 生物音效（鸡、牛、铁傀儡、猪、羊、骷髅、狼等） |
| `assets/minecraft/sounds/mob/wolf/classic/` | 狼的经典音效变体 |
| `assets/minecraft/sounds/portal/` | 传送门音效 |
| `assets/minecraft/sounds/random/` | 随机音效（原版经典音效替换） |
| `assets/minecraft/sounds/step/` | 脚步音效 |
| `assets/minecraft/sounds/tile/piston/` | 活塞音效 |
| `assets/minecraft/sounds/ui/` | UI音效（HUD、提示框） |
