### 16. `Dramatic Skys Demo 1.5.3.36.4` 文件索引

**包类型**: 天空与环境美化（演示版）
**兼容加载器**: OptiFine / MCPatcher / FabricSkyboxes / Celestial

#### 根目录
| 路径 | 功能 |
|---|---|
| `pack.mcmeta` | 资源包元数据文件，声明包版本与描述 |
| `pack.png` | 资源包封面图标 |
| `credit.txt` | 制作者致谢与版权信息 |

#### 关键目录
| 路径 | 功能 |
|---|---|
| `assets/celestial/sky/` | Celestial 模组天空配置（含 `dimensions.json`、`variables.json`） |
| `assets/celestial/sky/overworld/` | 主世界天空主配置 `sky.json` |
| `assets/celestial/sky/overworld/objects/` | 主世界天空对象定义（太阳、月亮、星空、日出日落等 20 个 JSON） |
| `assets/fabricskyboxes/sky/` | FabricSkyboxes 模组天空配置（兼容层，含 13 个天空 JSON） |
| `assets/minecraft/mcpatcher/sky/world0/` | MCPatcher 天空属性文件（sky1-sky9.properties） |
| `assets/minecraft/optifine/sky/world0/` | OptiFine 天空属性文件（sky1-sky9.properties） |
| `assets/minecraft/texts/` | 游戏文本（含 `splashes.txt` 闪屏文本） |
| `assets/minecraft/textures/environment/` | 环境纹理（云、日、月） |
| `assets/minecraft/textures/environment/celestial/moon/` | 月相纹理（8 个月相 PNG） |
| `assets/skybox/` | 天空盒纹理素材（白天、夜晚、星星、太阳、光晕等 PNG） |

#### 代表文件
| 路径 | 功能 |
|---|---|
| `assets/celestial/sky/overworld/objects/sun.json` | 太阳对象定义 |
