## 1. 概述

Minecraft 的声音系统是一个基于事件驱动的音频引擎，负责处理游戏中所有的声音播放、3D 定位、音量控制和衰减计算。声音文件存储在资源包的 `assets/minecraft/sounds/` 目录中，而声音事件的映射关系定义在 `assets/minecraft/sounds.json` 文件中。

### 1.1 声音系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Minecraft 声音系统架构                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  资源包层                                                    │
│  ├── sounds.json          声音事件定义                        │
│  └── sounds/              声音文件目录                        │
│      ├── mob/             生物声音                           │
│      ├── block/           方块声音                           │
│      ├── item/            物品声音                           │
│      ├── music/           背景音乐                           │
│      └── ...              其他分类                           │
│                                                             │
│  引擎层                                                     │
│  ├── 声音事件管理器        SoundEventManager                  │
│  ├── 声音管理器           SoundManager                       │
│  ├── 声音引擎             SoundEngine (OpenAL)               │
│  ├── 声音缓冲区管理        BufferManager                      │
│  └── 3D 音频处理器         Audio3DProcessor                   │
│                                                             │
│  输出层                                                     │
│  ├── 立体声输出            Stereo Output                      │
│  ├── 环绕声输出            Surround Output                    │
│  └── HRTF 处理            Head-Related Transfer Function     │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心概念

- **声音事件（Sound Event）**：游戏逻辑中触发声音的标识符，如 `entity.creeper.primed`
- **声音文件（Sound File）**：实际的音频文件，通常是 OGG Vorbis 格式
- **声音类别（Sound Category）**：声音的分类，用于音量控制，如 `hostile`、`block`
- **声音池（Sound Pool）**：一个声音事件可以对应多个声音文件，随机选择播放

## 2. 声音事件系统

### 2.1 声音事件标识符

声音事件使用点分隔的命名空间格式：

```
<namespace>.<category>.<subcategory>.<name>
```

**示例**：
```
minecraft:block.stone.break
minecraft:entity.creeper.primed
minecraft:item.bucket.fill
minecraft:music.game
minecraft:weather.rain
```

### 2.2 声音事件触发机制

声音事件由游戏代码中的特定操作触发：

```java
// 伪代码示例
world.playSound(player, blockPos, SoundEvents.BLOCK_STONE_BREAK, 
                SoundCategory.BLOCKS, 1.0F, 1.0F);
```

**触发参数**：
- `player`：触发声音的玩家（用于网络同步）
- `position`：声音播放位置
- `soundEvent`：声音事件标识符
- `category`：声音类别
- `volume`：音量（0.0-1.0，可超过1.0）
- `pitch`：音调（0.5-2.0）

### 2.3 声音事件注册

Minecraft 在初始化时注册所有声音事件。资源包可以通过 `sounds.json` 添加新的声音事件或扩展现有事件。

**声音事件注册流程**：
```
1. 加载资源包
2. 解析 sounds.json
3. 注册所有声音事件
4. 预加载标记为 preload 的声音
5. 准备就绪，等待触发
```

## 3. sounds.json 完整格式

### 3.1 文件位置

```
assets/minecraft/sounds.json
```

### 3.2 完整格式规范

```json
{
    "<sound_event_id>": {
        "replace": false,
        "subtitle": "subtitles.<sound_event_id>",
        "sounds": [
            {
                "name": "minecraft:<category>/<filename>",
                "volume": 1.0,
                "pitch": 1.0,
                "weight": 1,
                "stream": false,
                "attenuation_distance": 16,
                "preload": false,
                "type": "sound"
            }
        ]
    }
}
```

### 3.3 顶层字段详解

#### `replace` 标志

| 值 | 说明 |
|------|------|
| `false` | **默认值**。追加模式：将新的声音添加到现有事件的声音列表中 |
| `true` | 替换模式：完全替换现有事件的所有声音 |

**追加模式示例**：
```json
{
    "block.stone.break": {
        "sounds": [
            "block/stone/break1",
            "block/stone/break2"
        ]
    }
}
```

如果原版定义了 3 个声音，追加后将有 5 个声音，播放时随机选择。

**替换模式示例**：
```json
{
    "block.stone.break": {
        "replace": true,
        "sounds": [
            "custom/my_stone_break"
        ]
    }
}
```

替换后只有 1 个声音，原版的 3 个声音被完全移除。

#### `subtitle` 字段

定义声音事件的字幕标识符，用于辅助功能（字幕系统）。

```json
{
    "entity.creeper.primed": {
        "subtitle": "subtitles.entity.creeper.primed"
    }
}
```

字幕文本定义在语言文件中：
```json
{
    "subtitles.entity.creeper.primed": "Creeper hisses"
}
```

### 3.4 声音数组元素详解

每个声音事件包含一个 `sounds` 数组，数组中的每个元素可以是字符串（简写）或对象（完整格式）。

#### 简写格式

```json
{
    "block.stone.break": {
        "sounds": [
            "block/stone/break1",
            "block/stone/break2",
            "block/stone/break3"
        ]
    }
}
```

等价于：
```json
{
    "block.stone.break": {
        "sounds": [
            {
                "name": "minecraft:block/stone/break1",
                "volume": 1.0,
                "pitch": 1.0,
                "weight": 1,
                "stream": false,
                "attenuation_distance": 16,
                "preload": false,
                "type": "sound"
            },
            {
                "name": "minecraft:block/stone/break2",
                "volume": 1.0,
                "pitch": 1.0,
                "weight": 1,
                "stream": false,
                "attenuation_distance": 16,
                "preload": false,
                "type": "sound"
            },
            {
                "name": "minecraft:block/stone/break3",
                "volume": 1.0,
                "pitch": 1.0,
                "weight": 1,
                "stream": false,
                "attenuation_distance": 16,
                "preload": false,
                "type": "sound"
            }
        ]
    }
}
```

#### 完整对象格式

##### `name` 字段

声音文件的路径，格式为 `<namespace>:<path>`。

```
格式：minecraft:<category>/<subcategory>/<filename>
示例：minecraft:mob/creeper/death1
```

**路径规则**：
- 不包含文件扩展名（`.ogg` 自动添加）
- 使用正斜杠 `/` 作为路径分隔符
- 可以引用其他命名空间的声音：`othermod:sounds/custom`

##### `volume` 字段

控制该声音文件的相对音量。

| 范围 | 说明 |
|------|------|
| `0.0` | 静音 |
| `0.5` | 半音量 |
| `1.0` | **默认值**，原始音量 |
| `1.0+` | 放大音量（可能造成削波） |

```json
{
    "name": "mob/creeper/death1",
    "volume": 0.8
}
```

**注意**：`volume` 是相对值，最终音量还受主音量、类别音量和距离衰减影响。

##### `pitch` 字段

控制声音的音调（播放速度）。

| 范围 | 说明 |
|------|------|
| `0.5` | 最低音调（慢速播放，低沉） |
| `1.0` | **默认值**，原始音调 |
| `2.0` | 最高音调（快速播放，尖锐） |

```json
{
    "name": "mob/villager/haggle1",
    "pitch": 1.2
}
```

**注意**：改变音调会影响播放时长。音调为 0.5 时，播放时间翻倍；音调为 2.0 时，播放时间减半。

##### `weight` 字段

该声音文件被选中的权重（概率权重）。

```json
{
    "sounds": [
        { "name": "mob/cat/meow1", "weight": 8 },
        { "name": "mob/cat/meow2", "weight": 2 },
        { "name": "mob/cat/meow3", "weight": 1 }
    ]
}
```

**选择概率计算**：
```
meow1 概率 = 8 / (8 + 2 + 1) = 72.7%
meow2 概率 = 2 / (8 + 2 + 1) = 18.2%
meow3 概率 = 1 / (8 + 2 + 1) = 9.1%
```

**默认值**：1

##### `stream` 字段

控制声音是否使用流式播放。

| 值 | 说明 |
|------|------|
| `false` | **默认值**。预加载到内存，适合短音效 |
| `true` | 流式播放，边播放边从磁盘读取，适合长音频 |

```json
{
    "name": "music/game/calm1",
    "stream": true
}
```

**使用建议**：
- 短音效（< 5秒）：`stream: false`
- 长音频（> 5秒）：`stream: true`
- 背景音乐：`stream: true`
- 环境音效：`stream: false`

**性能影响**：
- `stream: false`：占用内存，但播放延迟低
- `stream: true`：节省内存，但有轻微的播放延迟

##### `attenuation_distance` 字段

声音的衰减距离（单位：方块）。

```json
{
    "name": "mob/ghast/charge1",
    "attenuation_distance": 80
}
```

| 值 | 说明 |
|------|------|
| `0` | 无衰减，全地图可闻 |
| `16` | **默认值**，标准衰减距离 |
| `64` | 长距离衰减 |
| `80+` | 非常远的衰减距离 |

**衰减公式**（线性衰减）：
```
effective_volume = volume * (1.0 - distance / attenuation_distance)
```

当 `distance >= attenuation_distance` 时，音量为 0。

**不同声音类型的典型衰减距离**：
- 方块声音：16 方块
- 实体声音：16-32 方块
- 爆炸声音：48-80 方块
- 闪电声音：160 方块
- 全局声音（音乐等）：使用 `type: "event"` 或超大衰减距离

##### `preload` 字段

控制声音文件是否在资源包加载时预加载到内存。

| 值 | 说明 |
|------|------|
| `false` | **默认值**。首次播放时加载 |
| `true` | 资源包加载时预加载 |

```json
{
    "name": "mob/creeper/primed",
    "preload": true
}
```

**适用场景**：
- 频繁播放的音效：`preload: true`
- 偶尔播放的音效：`preload: false`
- 短音效：`preload: true`
- 长音频：`preload: false`

##### `type` 字段

声音的类型。

| 值 | 说明 |
|------|------|
| `"sound"` | **默认值**。普通声音文件，从 `sounds/` 目录加载 |
| `"event"` | 声音事件引用，引用另一个声音事件 |

```json
{
    "ambient.cave": {
        "sounds": [
            {
                "name": "ambient/cave/cave1",
                "type": "sound"
            }
        ]
    },
    "my_custom_sound": {
        "sounds": [
            {
                "name": "minecraft:ambient.cave",
                "type": "event"
            }
        ]
    }
}
```

## 4. 声音类别

### 4.1 类别列表

Minecraft 使用声音类别来分组控制音量。玩家可以在设置中单独调节每个类别的音量。

| 类别 | 标识符 | 说明 | 典型声音 |
|------|--------|------|---------|
| 主音量 | `master` | 所有声音的总音量 | - |
| 音乐 | `music` | 背景音乐 | `music.game.*`、`music.nether.*` |
| 唱片 | `record` | 唱片机播放的音乐 | `music_disc.*` |
| 天气 | `weather` | 天气相关声音 | `weather.rain`、`weather.thunder` |
| 方块 | `block` | 方块交互声音 | `block.stone.break`、`block.door.open` |
| 敌对生物 | `hostile` | 敌对生物声音 | `entity.zombie.ambient`、`entity.creeper.primed` |
| 友好生物 | `neutral` | 友好生物声音 | `entity.sheep.ambient`、`entity.villager.trade` |
| 玩家 | `player` | 玩家相关声音 | `entity.player.hurt`、`entity.player.levelup` |
| 环境 | `ambient` | 环境声音 | `ambient.cave`、`ambient.underwater.enter` |
| 语音 | `voice` | 语音相关（自定义） | 自定义语音包 |

### 4.2 音量计算公式

最终播放音量由多个因素决定：

```
final_volume = master_volume 
             * category_volume 
             * sound_volume 
             * distance_attenuation 
             * occlusion_factor
```

**详细计算**：
```
base_volume = sound_event.volume * sound_file.volume
distance_factor = 1.0 - (distance / attenuation_distance)
occlusion_factor = 1.0 - (occlusion_blocks * 0.1)

final_volume = master_volume 
             * category_volume 
             * base_volume 
             * distance_factor 
             * occlusion_factor
```

## 5. 声音文件格式

### 5.1 支持的格式

Minecraft 主要支持 **OGG Vorbis** 格式的声音文件。

| 格式 | 支持程度 | 说明 |
|------|---------|------|
| OGG Vorbis | 完全支持 | 推荐格式，压缩率高，音质好 |
| WAV | 有限支持 | 仅用于某些系统声音 |
| MP3 | 不支持 | - |
| FLAC | 不支持 | - |
| AAC | 不支持 | - |

### 5.2 OGG Vorbis 规格

**推荐规格**：

| 参数 | 推荐值 | 可选范围 |
|------|--------|---------|
| 编码器 | Vorbis | - |
| 采样率 | 44100 Hz | 22050-48000 Hz |
| 声道 | 单声道（Mono） | 单声道/立体声 |
| 比特率 | 128 kbps | 64-256 kbps |
| 位深度 | 16 bit | 16 bit |

**文件大小参考**：
```
单声道，44100 Hz，128 kbps：
- 1秒 ≈ 16 KB
- 5秒 ≈ 80 KB
- 10秒 ≈ 160 KB
- 1分钟 ≈ 960 KB

立体声，44100 Hz，128 kbps：
- 1秒 ≈ 32 KB
- 5秒 ≈ 160 KB
- 10秒 ≈ 320 KB
- 1分钟 ≈ 1.9 MB
```

### 5.3 声道选择指南

**单声道（Mono）**：
- 适用：大部分游戏音效
- 原因：Minecraft 的 3D 音频引擎会自动处理空间化
- 优点：文件更小，3D 定位更准确

**立体声（Stereo）**：
- 适用：背景音乐、环境音效、唱片音乐
- 原因：立体声保留原始的空间信息
- 缺点：3D 定位效果较差

```json
// 单声道 - 用于 3D 定位的音效
{
    "entity.creeper.primed": {
        "sounds": [
            {
                "name": "mob/creeper/primed",
                "stream": false
            }
        ]
    }
}

// 立体声 - 用于背景音乐
{
    "music.game.calm1": {
        "sounds": [
            {
                "name": "music/game/calm1",
                "stream": true
            }
        ]
    }
}
```

### 5.4 音频转换工具

#### FFmpeg 命令行

```bash
# 转换为 Minecraft 兼容的 OGG 格式
ffmpeg -i input.wav -acodec libvorbis -ab 128k -ar 44100 -ac 1 output.ogg

# 批量转换
for f in *.wav; do
    ffmpeg -i "$f" -acodec libvorbis -ab 128k -ar 44100 -ac 1 "${f%.wav}.ogg"
done

# 调整音量
ffmpeg -i input.ogg -af "volume=0.8" -acodec libvorbis output.ogg

# 裁剪音频（从第2秒开始，持续3秒）
ffmpeg -i input.ogg -ss 2 -t 3 -acodec libvorbis output.ogg

# 归一化音量
ffmpeg -i input.ogg -af loudnorm -acodec libvorbis output.ogg
```

#### Audacity

1. 导入音频文件
2. 调整采样率：**轨道 → 设置速率 → 44100 Hz**
3. 转换为单声道：**轨道 → 混音 → 立体声转单声道**
4. 导出：**文件 → 导出为 OGG**

## 7. 声音替换方法

### 7.1 完全替换

使用 `"replace": true` 完全替换声音事件的所有声音。

**场景**：替换僵尸的声音为自定义声音。

```json
{
    "entity.zombie.ambient": {
        "replace": true,
        "subtitle": "subtitles.entity.zombie.ambient",
        "sounds": [
            "custom/zombie/custom_ambient1",
            "custom/zombie/custom_ambient2",
            "custom/zombie/custom_ambient3"
        ]
    },
    "entity.zombie.death": {
        "replace": true,
        "subtitle": "subtitles.entity.zombie.death",
        "sounds": [
            "custom/zombie/custom_death"
        ]
    },
    "entity.zombie.hurt": {
        "replace": true,
        "subtitle": "subtitles.entity.zombie.hurt",
        "sounds": [
            "custom/zombie/custom_hurt1",
            "custom/zombie/custom_hurt2"
        ]
    }
}
```

### 7.2 追加声音

使用默认的 `"replace": false`（或省略）向现有事件添加新声音。

**场景**：为石头方块添加额外的破坏音效。

```json
{
    "block.stone.break": {
        "sounds": [
            "custom/stone/extra_break1",
            "custom/stone/extra_break2"
        ]
    }
}
```

原版的 4 个声音加上新增的 2 个声音，共 6 个声音随机选择。

### 7.3 静音替换

使用空声音列表或极低音量来静音特定声音。

**方法一：空声音列表**
```json
{
    "entity.ghast.scream": {
        "replace": true,
        "sounds": []
    }
}
```

**方法二：极低音量**
```json
{
    "entity.ghast.scream": {
        "replace": true,
        "sounds": [
            {
                "name": "mob/ghast/scream1",
                "volume": 0.001
            }
        ]
    }
}
```

### 7.4 条件替换

虽然 `sounds.json` 本身不支持条件逻辑，但可以通过资源包的覆盖层（Overlay）系统实现版本特定的声音替换。

### 7.5 声音文件替换

除了修改 `sounds.json`，还可以直接替换声音文件：

```
assets/minecraft/sounds/mob/zombie/say1.ogg
assets/minecraft/sounds/mob/zombie/say2.ogg
assets/minecraft/sounds/mob/zombie/say3.ogg
```

只需保持相同的文件路径和名称，新的声音文件会自动覆盖原版文件。

## 8. 3D 声音定位

### 8.1 3D 音频原理

Minecraft 使用 OpenAL 进行 3D 音频处理，支持以下特性：

- **距离衰减**：声音随距离减弱
- **左右声道平衡**：根据声源相对位置调整左右声道
- **遮挡计算**：方块会遮挡声音传播
- **多普勒效应**：声源移动时的频率变化（有限支持）

### 8.2 距离衰减模型

Minecraft 使用线性距离衰减模型：

```
volume_factor = 1.0 - (distance / attenuation_distance)
volume_factor = clamp(volume_factor, 0.0, 1.0)
```

**距离衰减图**：
```
音量
1.0 ┤●━━━━━━━━━━━━━━━━━━━━━━━━━━━
    │ ╲
0.8 ┤  ╲
    │   ╲
0.6 ┤    ╲
    │     ╲
0.4 ┤      ╲
    │       ╲
0.2 ┤        ╲
    │         ╲
0.0 ┤━━━━━━━━━━●━━━━━━━━━━━━━━━━━
    0    4    8   12   16   20   24
              距离（方块）
    
    衰减距离 = 16 方块
```

### 8.3 遮挡计算（Occlusion）

当声源与听众之间有方块时，声音会被遮挡。遮挡因子计算：

```java
// 伪代码
float calculateOcclusion(Vec3 listenerPos, Vec3 sourcePos) {
    // 从监听者到声源的射线
    Ray ray = new Ray(listenerPos, sourcePos);
    
    // 计算穿过的方块数量
    int blockCount = countBlocksAlongRay(ray);
    
    // 每个方块减少 10% 音量
    float occlusion = 1.0 - (blockCount * 0.1);
    return max(occlusion, 0.0);  // 最低为 0
}
```

**示例**：
- 无遮挡：1.0（100% 音量）
- 1 个方块遮挡：0.9（90% 音量）
- 5 个方块遮挡：0.5（50% 音量）
- 10+ 个方块遮挡：0.0（静音）

### 8.4 立体声定位

Minecraft 根据声源相对于玩家视角的位置来调整左右声道：

```
声源在玩家左侧：左声道更响
声源在玩家右侧：右声道更响
声源在玩家正前方/正后方：左右声道平衡
```

**定位计算**：
```java
// 伪代码
Vec3 toSource = sourcePos - listenerPos;
Vec3 listenerRight = listenerView.cross(UP);

float stereoFactor = toSource.normalize().dot(listenerRight);
// stereoFactor: -1.0（最左）到 1.0（最右）

float leftVolume = (1.0 - stereoFactor) * 0.5;
float rightVolume = (1.0 + stereoFactor) * 0.5;
```

### 8.5 全局声音

某些声音是全局的，不受距离衰减影响：

**实现方式一：type: "event"**

## 9. 背景音乐系统

### 9.1 音乐播放机制

Minecraft 的背景音乐系统具有以下特点：

- **随机间隔**：音乐之间有 2-8 分钟的随机间隔
- **单曲播放**：同一时间只播放一首音乐
- **淡入淡出**：音乐有淡入和淡出效果
- **场景感知**：不同维度播放不同音乐
- **条件触发**：特定条件下播放特定音乐

### 9.2 音乐触发条件

| 音乐事件 | 触发条件 |
|---------|---------|
| `music.game` | 主世界常规探索 |
| `music.game.creative` | 创造模式 |
| `music.game.nether` | 下界探索 |
| `music.game.end` | 末地探索 |
| `music.game.end.boss` | 末影龙战斗 |
| `music.under_water` | 水下探索 |
| `music.menu` | 主菜单 |

### 9.3 唱片机音乐

唱片机使用不同的播放机制：

- **3D 定位**：从唱片机方块位置播放
- **固定衰减距离**：64 方块
- **可被红石停止**：移除唱片后停止
- **互斥**：同一时间只能播放一张唱片

## 10. 常见问题与解决方案

### 10.1 声音文件无法播放

**症状**：声音事件触发但没有声音

**检查清单**：

1. **文件路径正确性**
```json
// 正确
"name": "mob/zombie/say1"

// 错误：缺少子目录
"name": "zombie/say1"

// 错误：包含文件扩展名
"name": "mob/zombie/say1.ogg"
```

2. **文件格式正确**
```bash
# 检查文件格式
file sounds/mob/zombie/say1.ogg
# 应输出：Ogg data, Vorbis audio

# 使用 ffprobe 检查详细信息
ffprobe sounds/mob/zombie/say1.ogg
```

3. **JSON 语法正确**
```bash
# 使用 jq 验证 JSON 语法
cat sounds.json | jq .

# 常见错误
# - 缺少逗号
# - 多余的逗号
# - 引号不匹配
```

4. **编码格式兼容**
```bash
# 检查音频编码
ffprobe -v error -show_streams sounds/mob/zombie/say1.ogg | grep codec_name
# 应输出：codec_name=vorbis
```

### 10.2 声音音量异常

**症状**：声音太小或太大

**解决方案**：

```json
{
    "block.stone.break": {
        "sounds": [
            {
                "name": "block/stone/break1",
                "volume": 0.5  // 降低音量
            }
        ]
    }
}
```

**音量调节建议**：
- 短促音效（击打、脚步）：0.5-1.0
- 环境音效（风声、水声）：0.3-0.5
- 背景音乐：0.4-0.7
- 爆炸音效：0.8-1.2

### 10.3 声音循环问题

**症状**：声音无限循环或提前停止

**解决方案**：

```json
{
    "ambient.cave": {
        "sounds": [
            {
                "name": "ambient/cave/cave1",
                "stream": true,
                "preload": true
            }
        ]
    }
}
```

**循环音效建议**：
- 使用 `stream: true` 避免内存问题
- 确保音频文件本身是无缝循环的
- 使用足够长的音频文件（至少 10 秒）

### 10.4 3D 定位不准确

**症状**：声音听起来没有方向感

**检查项目**：

1. **使用单声道音频**
```bash
# 检查声道数
ffprobe -v error -show_streams input.ogg | grep channels
# 应输出：channels=1

# 转换为单声道
ffmpeg -i input_stereo.ogg -ac 1 output_mono.ogg
```

2. **检查衰减距离**
```json
{
    "my_sound": {
        "sounds": [
            {
                "name": "custom/sound",
                "attenuation_distance": 16  // 适当的衰减距离
            }
        ]
    }
}
```

3. **确认声音类别**
```java
// 确保使用正确的类别播放
world.playSound(pos, soundEvent, SoundCategory.NEUTRAL, volume, pitch);
```

### 10.5 内存占用过高

**症状**：游戏内存占用增加

**优化建议**：

```json
{
    "my_long_sound": {
        "sounds": [
            {
                "name": "custom/long_ambient",
                "stream": true,      // 流式播放
                "preload": false      // 不预加载
            }
        ]
    }
}
```

**内存优化策略**：
- 长音频（>5秒）使用 `stream: true`
- 不常用的声音不使用 `preload: true`
- 使用适当的压缩比特率（128kbps 通常足够）


### 11.2 命名规范

**文件命名**：
- 使用小写字母和下划线
- 避免空格和特殊字符
- 使用描述性名称

```
# 正确
mob/zombie/ambient1.ogg
block/stone/break1.ogg
item/sword/swoosh1.ogg

# 错误
mob/Zombie/Ambient 1.ogg
block/Stone Break.ogg
```

**事件命名**：
- 遵循 Minecraft 的命名约定
- 使用点分隔的层次结构

```json
// 正确
"entity.my_mob.ambient"
"block.my_block.break"
"item.my_item.use"

// 错误
"myMobAmbient"
"my_block_break"
```

### 11.3 音频质量

**录制建议**：
- 采样率：44100 Hz
- 位深度：16 bit
- 格式：WAV（录制）→ OGG Vorbis（最终）

**后期处理**：
```bash
# 1. 归一化音量
ffmpeg -i input.wav -af loudnorm output_normalized.wav

# 2. 去除静音
ffmpeg -i input.wav -af silenceremove=start_periods=1:start_duration=0.1:start_threshold=-50dB output_trimmed.wav

# 3. 转换为 OGG
ffmpeg -i output_normalized.wav -acodec libvorbis -ab 128k -ar 44100 -ac 1 final.ogg
```
