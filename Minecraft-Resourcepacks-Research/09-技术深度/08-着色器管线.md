## 1. 概述

Minecraft Java Edition 自 1.7 版本起引入了基于 GLSL 的着色器系统，在 1.17 版本中进行了重大重构（从 OpenGL 固定管线迁移至可编程管线）。着色器是资源包中最强大的自定义工具之一，它们直接控制游戏的渲染方式，从方块纹理的采样到全屏后处理效果，都可以通过着色器来实现。

### 1.1 着色器的定义

着色器（Shader）是一段运行在 GPU 上的小型程序，用于控制图形渲染管线中特定阶段的行为。Minecraft 使用两类着色器：

- **顶点着色器（Vertex Shader, `.vsh`）**：处理每个顶点的位置变换、颜色计算和纹理坐标映射
- **片段着色器（Fragment Shader, `.fsh`）**：决定每个像素（片段）的最终颜色输出

### 1.2 着色器在资源包中的角色

在资源包体系中，着色器文件位于 `assets/minecraft/shaders/` 目录下。与纹理、模型等静态数据不同，着色器是可执行的 GPU 代码，能够：

- 改变光照计算方式
- 实现自定义后处理效果（模糊、色调映射、景深等）
- 修改特定渲染类型的外观（水面、实体、粒子等）
- 实现全亮（Fullbright）、轮廓描边等游戏玩法相关效果

## 2. 渲染管线概览

### 2.1 Minecraft 渲染管线架构

Minecraft 的渲染管线可以分为以下几个主要阶段：

```
┌─────────────────────────────────────────────────────────────┐
│                    Minecraft 渲染管线                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 场景准备阶段                                              │
│     ├── 可见性剔除（Frustum Culling）                         │
│     ├── 透明度排序（Transparency Sorting）                    │
│     └── 批次构建（Batch Building）                            │
│                                                             │
│  2. 几何渲染阶段                                              │
│     ├── 顶点着色器（Vertex Shader）                           │
│     ├── 图元装配（Primitive Assembly）                        │
│     ├── 光栅化（Rasterization）                              │
│     └── 片段着色器（Fragment Shader）                         │
│                                                             │
│  3. 特定渲染类型阶段                                          │
│     ├── rendertype_solid       - 不透明方块                   │
│     ├── rendertype_cutout      - 有透明像素的方块              │
│     ├── rendertype_translucent - 半透明方块（水、冰等）         │
│     ├── rendertype_entity_*    - 实体渲染                     │
│     ├── rendertype_text_*      - 文本渲染                     │
│     └── rendertype_*           - 其他渲染类型                  │
│                                                             │
│  4. 后处理阶段                                               │
│     ├── 颜色空间转换（Color Convolve）                        │
│     ├── 模糊效果（Blur）                                     │
│     ├── 景深（Depth of Field）                               │
│     ├── 运动模糊（Motion Blur）                              │
│     └── 抗锯齿（FXAA / TAA）                                 │
│                                                             │
│  5. 最终输出                                                 │
│     └── 帧缓冲区 → 屏幕显示                                   │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 渲染状态管理

Minecraft 在渲染不同类型的几何体时，会设置不同的 OpenGL 渲染状态：

| 渲染状态 | 深度测试 | 混合模式 | 剔除模式 | 适用场景 |
|---------|---------|---------|---------|---------|
| Solid | 启用 | 禁用 | 背面剔除 | 不透明方块 |
| Cutout | 启用 | 禁用 | 背面剔除 | 树叶、铁栏杆 |
| Translucent | 启用 | Alpha混合 | 背面剔除 | 水、冰、彩色玻璃 |
| Entity | 启用 | 可变 | 可变 | 实体模型 |
| Text | 启用 | Alpha混合 | 禁用 | UI文本 |

### 2.3 帧缓冲区（Framebuffer）

Minecraft 使用多个帧缓冲区来实现不同的渲染效果：

- **主帧缓冲区**：存储最终颜色和深度信息
- **阴影缓冲区**（模组）：用于阴影映射
- **后处理缓冲区**：用于中间后处理结果
- **Glow缓冲区**：用于发光实体的描边效果

## 3. 核心着色器 vs 模组着色器

### 3.1 核心着色器（Core Shaders）

核心着色器是 Minecraft 原生提供的着色器系统，从 1.17 版本开始全面采用。它们位于 `assets/minecraft/shaders/core/` 目录下。

**特点**：
- 由 Minecraft 原生支持，无需额外模组
- 功能相对有限，但兼容性最好
- 覆盖所有渲染类型
- 支持通过资源包替换

**限制**：
- 不支持阴影映射
- 不支持延迟渲染
- 后处理效果有限
- 无法添加自定义渲染通道

### 3.2 OptiFine / Iris 着色器

OptiFine 和 Iris（Fabric）等模组提供了更强大的着色器系统。

**OptiFine 着色器目录结构**：
```
shaders/
├── shaders.properties          # 着色器配置文件
├── gbuffers_basic.vsh/.fsh     # 基础几何体
├── gbuffers_terrain.vsh/.fsh   # 地形（方块）
├── gbuffers_entities.vsh/.fsh  # 实体
├── gbuffers_textured.vsh/.fsh  # 带纹理的几何体
├── gbuffers_water.vsh/.fsh     # 水面
├── gbuffers_skybasic.vsh/.fsh  # 天空基础
├── gbuffers_skytextured.vsh/.fsh # 天空纹理（太阳/月亮）
├── composite.vsh/.fsh          # 合成通道
├── composite1.vsh/.fsh         # 合成通道1
├── final.vsh/.fsh              # 最终输出
├── shadow.vsh/.fsh             # 阴影通道
└── program.vsh/.fsh            # 自定义通道
```

**Iris 着色器**：
Iris 是 Fabric 生态的着色器加载器，兼容大部分 OptiFine 着色器包，同时提供更好的性能和模组兼容性。

### 3.3 对比表

| 特性 | 核心着色器 | OptiFine 着色器 | Iris 着色器 |
|------|----------|----------------|------------|
| 原生支持 | 是（1.17+） | 需要模组 | 需要模组 |
| 阴影映射 | 否 | 是 | 是 |
| 延迟渲染 | 否 | 部分支持 | 是（通过Canvas） |
| 自定义通道 | 有限 | 是 | 是 |
| 性能影响 | 低 | 中等 | 低-中 |
| 兼容性 | 最好 | 好 | 好 |
| 修改方式 | 资源包 | 着色器包 | 着色器包 |

### 4.2 目录说明

**`core/`**：包含所有核心渲染类型对应的着色器程序。每个渲染类型由一对 `.vsh` 和 `.fsh` 文件组成。这些着色器直接绑定到特定的渲染状态和顶点格式。

**`post/`**：后处理着色器。每个后处理效果由三个文件组成：`.json` 配置文件、`.vsh` 顶点着色器、`.fsh` 片段着色器。后处理着色器在主场景渲染完成后对整个屏幕进行处理。

**`program/`**：自定义着色器程序目录。用户可以在此添加自定义的着色器程序，供后处理管线引用。

**`include/`**：共享着色器代码目录（1.20.4+新增）。可以存放被多个着色器共用的 `.glsl` 文件，通过 `#include` 指令引用。

## 5. 文件格式详解

### 5.1 GLSL 文件格式（.vsh / .fsh / .glsl）

**文件编码**：UTF-8（推荐）、ASCII  
**行结束符**：LF（`\n`）或 CRLF（`\r\n`）  
**注释**：支持 C 风格注释（`//` 和 `/* */`）

**`.vsh` 文件** - 顶点着色器：
```glsl
#version 150

// 顶点属性输入
in vec3 Position;
in vec4 Color;
in vec2 UV0;
in vec2 UV2;

// Uniform 变量
uniform mat4 ModelViewMat;
uniform mat4 ProjMat;
uniform mat3 IViewRotMat;
uniform float GameTime;

// 传递给片段着色器的变量
out vec4 vertexColor;
out vec2 texCoord;
out vec2 lightMapCoord;

void main() {
    gl_Position = ProjMat * ModelViewMat * vec4(Position, 1.0);
    vertexColor = Color;
    texCoord = UV0;
    lightMapCoord = UV2;
}
```

**`.fsh` 文件** - 片段着色器：
```glsl
#version 150

// 从顶点着色器接收的变量
in vec4 vertexColor;
in vec2 texCoord;
in vec2 lightMapCoord;

// Uniform 变量
uniform sampler2D Sampler0;    // 纹理采样器
uniform sampler2D Sampler2;    // 光照贴图采样器

// 输出
out vec4 fragColor;

void main() {
    vec4 texColor = texture(Sampler0, texCoord);
    vec4 lightColor = texture(Sampler2, lightMapCoord);
    vec4 color = texColor * vertexColor * lightColor;
    
    if (color.a < 0.1) {
        discard;  // 丢弃透明片段
    }
    
    fragColor = color;
}
```

**`.glsl` 文件** - 共享代码（1.20.4+）：
```glsl
// 公共工具函数
vec4 linear_fog(vec4 inColor, float fogStart, float fogEnd, float vertexDistance, vec4 fogColor) {
    float fogValue = smoothstep(fogStart, fogEnd, vertexDistance);
    return vec4(mix(inColor.rgb, fogColor.rgb, fogValue * fogColor.a), inColor.a);
}

float linear_fog_fade(float fogStart, float fogEnd, float vertexDistance) {
    return smoothstep(fogEnd, fogStart, vertexDistance);
}
```

### 5.2 JSON 配置文件格式

后处理着色器使用 JSON 格式的配置文件来定义渲染管线。以下是完整格式说明：

**后处理配置文件完整格式**：
```json
{
    "targets": [
        "swap",
        "previous"
    ],
    "passes": [
        {
            "name": "blur",
            "intarget": "minecraft:main",
            "outtarget": "swap",
            "auxtargets": [
                {
                    "name": "DepthSampler",
                    "id": "minecraft:main",
                    "attachment": "depth"
                },
                {
                    "name": "LightSampler",
                    "id": "minecraft:main",
                    "attachment": "color",
                    "width": 1,
                    "height": 1
                }
            ],
            "uniforms": [
                {
                    "name": "BlurDir",
                    "values": [1.0, 0.0]
                },
                {
                    "name": "Radius",
                    "values": [4.0]
                }
            ]
        },
        {
            "name": "blur",
            "intarget": "swap",
            "outtarget": "previous",
            "uniforms": [
                {
                    "name": "BlurDir",
                    "values": [0.0, 1.0]
                }
            ]
        }
    ]
}
```

**JSON 字段详解**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `targets` | `string[]` | 声明的中间渲染目标（帧缓冲区） |
| `passes` | `object[]` | 后处理通道列表，按顺序执行 |
| `passes[].name` | `string` | 引用的着色器程序名称（对应 `program/` 目录下的文件） |
| `passes[].intarget` | `string` | 输入渲染目标（`"minecraft:main"` 或自定义名称） |
| `passes[].outtarget` | `string` | 输出渲染目标 |
| `passes[].auxtargets` | `object[]` | 辅助渲染目标（额外的纹理绑定） |
| `passes[].auxtargets[].name` | `string` | 在着色器中使用的采样器名称 |
| `passes[].auxtargets[].id` | `string` | 来源渲染目标 ID |
| `passes[].auxtargets[].attachment` | `string` | 附件类型（`"color"` 或 `"depth"`） |
| `passes[].uniforms` | `object[]` | Uniform 变量初始值 |
| `passes[].uniforms[].name` | `string` | Uniform 变量名称 |
| `passes[].uniforms[].values` | `number[]` | 变量值（数组形式，1-4个元素） |

## 6. 核心着色器程序

### 6.1 基础着色器

#### `position` - 纯位置着色器

用于不带纹理和颜色的几何体渲染，如天空盒。

**顶点格式**：`Position (vec3)`

```glsl
// position.vsh
#version 150

in vec3 Position;

uniform mat4 ModelViewMat;
uniform mat4 ProjMat;

out float vertexDistance;

void main() {
    gl_Position = ProjMat * ModelViewMat * vec4(Position, 1.0);
    vertexDistance = length((ModelViewMat * vec4(Position, 1.0)).xyz);
}
```

```glsl
// position.fsh
#version 150

uniform vec4 ColorModulator;
uniform float FogStart;
uniform float FogEnd;
uniform vec4 FogColor;

in float vertexDistance;

out vec4 fragColor;

void main() {
    vec4 color = vec4(1.0, 1.0, 1.0, 1.0);
    float fogValue = smoothstep(FogStart, FogEnd, vertexDistance);
    fragColor = mix(color, FogColor, fogValue) * ColorModulator;
}
```

#### `position_color` - 位置+颜色着色器

用于带顶点颜色的几何体，如调试线条、粒子。

**顶点格式**：`Position (vec3), Color (vec4)`

```glsl
// position_color.vsh
#version 150

in vec3 Position;
in vec4 Color;

uniform mat4 ModelViewMat;
uniform mat4 ProjMat;

out vec4 vertexColor;
out float vertexDistance;

void main() {
    gl_Position = ProjMat * ModelViewMat * vec4(Position, 1.0);
    vertexColor = Color;
    vertexDistance = length((ModelViewMat * vec4(Position, 1.0)).xyz);
}
```

#### `position_tex` - 位置+纹理着色器

用于带纹理但不带顶点颜色的几何体。

**顶点格式**：`Position (vec3), UV0 (vec2)`

#### `position_tex_color` - 位置+纹理+颜色着色器

用于带纹理和顶点颜色的几何体，如粒子效果。

**顶点格式**：`Position (vec3), UV0 (vec2), Color (vec4)`

```glsl
// position_tex_color.vsh
#version 150

in vec3 Position;
in vec2 UV0;
in vec4 Color;

uniform mat4 ModelViewMat;
uniform mat4 ProjMat;

out vec2 texCoord;
out vec4 vertexColor;

void main() {
    gl_Position = ProjMat * ModelViewMat * vec4(Position, 1.0);
    texCoord = UV0;
    vertexColor = Color;
}
```

### 6.2 渲染类型着色器（rendertype_*）

#### `rendertype_solid` - 不透明方块

这是最常用的着色器，用于渲染不透明方块（石头、泥土、金属等）。

**顶点格式**：`Position (vec3), Color (vec4), UV0 (vec2), UV2 (vec2), Normal (vec3)`

```glsl
// rendertype_solid.vsh
#version 150

in vec3 Position;
in vec4 Color;
in vec2 UV0;
in vec2 UV2;
in vec3 Normal;

uniform mat4 ModelViewMat;
uniform mat4 ProjMat;
uniform float GameTime;
uniform vec3 ChunkOffset;

out vec4 vertexColor;
out vec2 texCoord;
out vec2 lightMapCoord;
out vec3 normal;
out float vertexDistance;

void main() {
    vec3 pos = Position + ChunkOffset;
    gl_Position = ProjMat * ModelViewMat * vec4(pos, 1.0);
    vertexColor = Color;
    texCoord = UV0;
    lightMapCoord = UV2;
    normal = Normal;
    vertexDistance = length((ModelViewMat * vec4(pos, 1.0)).xyz);
}
```

```glsl
// rendertype_solid.fsh
#version 150

uniform sampler2D Sampler0;
uniform sampler2D Sampler2;
uniform vec4 ColorModulator;
uniform float FogStart;
uniform float FogEnd;
uniform vec4 FogColor;

in vec4 vertexColor;
in vec2 texCoord;
in vec2 lightMapCoord;
in vec3 normal;
in float vertexDistance;

out vec4 fragColor;

void main() {
    vec4 color = texture(Sampler0, texCoord);
    if (color.a < 0.5) {
        discard;
    }
    color *= vertexColor;
    color *= texture(Sampler2, lightMapCoord);
    color *= ColorModulator;
    
    float fogValue = smoothstep(FogStart, FogEnd, vertexDistance);
    fragColor = mix(color, FogColor, fogValue);
}
```

#### `rendertype_translucent` - 半透明方块

用于渲染半透明几何体，如水、冰、彩色玻璃。关键区别在于启用了 Alpha 混合且需要按深度排序。

```glsl
// rendertype_translucent.fsh 关键差异
#version 150

// ... 相同的 uniform 和 in 变量 ...

void main() {
    vec4 color = texture(Sampler0, texCoord);
    // 注意：半透明不使用 discard，而是保留 Alpha 通道
    color *= vertexColor;
    color *= texture(Sampler2, lightMapCoord);
    color *= ColorModulator;
    
    if (color.a < 0.003921569) {  // 1/255

}
```

## 7. 后处理着色器

### 7.1 后处理管线

后处理着色器在主场景渲染完成后执行，对整个屏幕进行图像处理。后处理的执行顺序由 `post/*.json` 文件中的 `passes` 数组定义。

### 7.2 后处理效果详解

#### `blur` - 模糊效果

用于实现高斯模糊，通常用于背景虚化、蜘蛛/凋灵中毒效果。

**JSON 配置**：
```json
{
    "targets": ["swap"],
    "passes": [
        {
            "name": "blur",
            "intarget": "minecraft:main",
            "outtarget": "swap",
            "uniforms": [
                { "name": "BlurDir", "values": [1.0, 0.0] },
                { "name": "Radius", "values": [4.0] }
            ]
        },
        {
            "name": "blur",
            "intarget": "swap",
            "outtarget": "minecraft:main",
            "uniforms": [
                { "name": "BlurDir", "values": [0.0, 1.0] },
                { "name": "Radius", "values": [4.0] }
            ]
        }
    ]
}
```

**着色器实现**：
```glsl
// blur.fsh
#version 150

uniform sampler2D DiffuseSampler;
uniform vec2 OutSize;
uniform vec2 BlurDir;
uniform float Radius;

in vec2 texCoord;
out vec4 fragColor;

void main() {
    vec2 texelSize = 1.0 / OutSize;
    vec4 result = vec4(0.0);
    float totalWeight = 0.0;
    
    float radius = Radius;
    for (float i = -radius; i <= radius; i += 1.0) {
        float weight = exp(-(i * i) / (2.0 * radius * radius / 4.0));
        vec2 offset = BlurDir * texelSize * i;
        result += texture(DiffuseSampler, texCoord + offset) * weight;
        totalWeight += weight;
    }
    
    fragColor = result / totalWeight;
}
```

#### `color_convolve` - 颜色空间转换

用于实现颜色滤镜效果，如夜视效果（绿色调）、蜘蛛视角（红色调）。

**JSON 配置**：

```json
                { "name": "GreenMatrix", "values": [0.0, 1.0, 0.0, 0.0] },
                { "name": "BlueMatrix", "values": [0.0, 0.0, 1.0, 0.0] },
                { "name": "AlphaMatrix", "values": [0.Matrix", "values": [0.0, 0.0, 1.0, 0.0] },
                { "name": "AlphaMatrix", "values": [0.0, 0.0, 0.0, 1.0] }

        }
    ]

```

**着色器实现**：

#### `depth_of_field` - 景深效果

根据深度信息实现焦点外的模糊效果。

**着色器实现**：
```glsl
// depth_of_field.fsh
#version 150

uniform sampler2D DiffuseSampler;
uniform sampler2D DepthSampler;
uniform vec2 OutSize;
uniform float FocusDistance;
uniform float FocusRange;
uniform float BlurRange;

in vec2 texCoord;
out vec4 fragColor;

float getDepth(vec2 uv) {
    return texture(DepthSampler, uv).r;
}

float getBlurSize(float depth) {
    float coc = abs(depth - FocusDistance) / FocusRange;
    return clamp(coc, 0.0, 1.0) * BlurRange;
}

void main() {
    float centerDepth = getDepth(texCoord);
    float blurSize = getBlurSize(centerDepth);
    
    vec4 result = vec4(0.0);
    float totalWeight = 0.0;
    
    int samples = 16;
    for (int i = -samples; i <= samples; i++) {
        for (int j = -samples; j <= samples; j++) {
            vec2 offset = vec2(float(i), float(j)) * blurSize / OutSize;
            vec2 sampleCoord = texCoord + offset;
            
            float sampleDepth = getDepth(sampleCoord);
            float sampleBlur = getBlurSize(sampleDepth);
            
            float weight = 1.0;
            if (sampleBlur < blurSize) {
                weight = 0.5;
            }
            
            result += texture(DiffuseSampler, sampleCoord) * weight;
            totalWeight += weight;
        }
    }
    
    fragColor = result / totalWeight;
}
```

#### `fxaa` - 快速近似抗锯齿

FXAA 是一种后处理抗锯齿技术，通过检测和柔化边缘来减少锯齿。

**着色器实现**：
```glsl
// fxaa.fsh
#version 150

uniform sampler2D DiffuseSampler;
uniform vec2 OutSize;
uniform float QualitySubpix;
uniform float QualityEdgeThreshold;
uniform float QualityEdgeThresholdMin;

in vec2 texCoord;
out vec4 fragColor;

void main() {
    vec2 texelSize = 1.0 / OutSize;
    
    // 采样周围像素
    float rgbNW = texture(DiffuseSampler, texCoord + vec2(-1.0, -1.0) * texelSize).r;
    float rgbNE = texture(DiffuseSampler, texCoord + vec2(1.0, -1.0) * texelSize).r;
    float rgbSW = texture(DiffuseSampler, texCoord + vec2(-1.0, 1.0) * texelSize).r;
    float rgbSE = texture(DiffuseSampler, texCoord + vec2(1.0, 1.0) * texelSize).r;
    float rgbM  = texture(DiffuseSampler, texCoord).r;
    
    // 计算边缘检测
    float lumaMin = min(rgbM, min(min(rgbNW, rgbNE), min(rgbSW, rgbSE)));
    float lumaMax = max(rgbM, max(max(rgbNW, rgbNE), max(rgbSW, rgbSE)));
    float lumaRange = lumaMax - lumaMin;
    
    if (lumaRange < max(QualityEdgeThresholdMin, lumaMax * QualityEdgeThreshold)) {
        fragColor = texture(DiffuseSampler, texCoord);
        return;
    }
    
    // 边缘混合计算
    // ... (完整 FXAA 算法实现)
    
    fragColor = texture(DiffuseSampler, texCoord);  // 简化示例
}
```

#### `outline` - 轮廓描边

用于实体选中时的轮廓效果。

```glsl
// outline.fsh
#version 150

uniform sampler2D DiffuseSampler;
uniform sampler2D OutlineSampler;
uniform vec4 ColorModulator;
uniform vec4 OutlineColor;

in vec2 texCoord;
out vec4 fragColor;

void main() {

    }
}
```

### 9.2 向量操作

```glsl
// 分量访问
```

## 10. 修改实例

### 10.1 全亮效果（Fullbright）

让所有方块和实体以最大亮度渲染，忽略光照系统。

**方法一：修改 rendertype_solid.fsh**

```glsl
#version 150

uniform sampler2D Sampler0;
uniform sampler2D Sampler2;
uniform vec4 ColorModulator;
uniform float FogStart;
uniform float FogEnd;
uniform vec4 FogColor;

in vec4 vertexColor;
in vec2 texCoord;
in vec2 lightMapCoord;
in vec3 normal;
in float vertexDistance;

out vec4 fragColor;

void main() {
    vec4 color = texture(Sampler0, texCoord);
    if (color.a < 0.5) {
        discard;
    }
    color *= vertexColor;
    
    // 全亮：忽略光照贴图，直接使用最大亮度
    // color *= texture(Sampler2, lightMapCoord);
    color *= vec4(1.0, 1.0, 1.0, 1.0);  // 最大亮度
    
    color *= ColorModulator;
    
    float fogValue = smoothstep(FogStart, FogEnd, vertexDistance);
    fragColor = mix(color, FogColor, fogValue);
}
```

**方法二：修改光照贴图采样**

```glsl
// 在片段着色器中覆盖光照贴图采样

```

**方法三：使用光照贴图坐标偏移**

```glsl
// 将光照贴图坐标固定为最大值
```

### 10.3 轮廓描边效果

为实体添加彩色轮廓。

```glsl
// rendertype_entity_solid.fsh - 添加轮廓
#version 150

uniform sampler2D Sampler0;
uniform sampler2D Sampler2;
uniform vec4 ColorModulator;
uniform float FogStart;
uniform float FogEnd;
uniform vec4 FogColor;

in vec4 vertexColor;
in vec2 texCoord;
in vec2 lightMapCoord;
in vec3 normal;
in float vertexDistance;

out vec4 fragColor;

void main() {
    vec4 color = texture(Sampler0, texCoord);
    if (color.a < 0.5) {
        discard;
    }
    
    color *= vertexColor;
    color *= texture(Sampler2, lightMapCoord);
    color *= ColorModulator;
    
    // 边缘检测（基于法线变化）
    vec3 dNormaldx = dFdx(normal);
    vec3 dNormaldy = dFdy(normal);
    float edgeFactor = length(dNormaldx) + length(dNormaldy);
    
    // 如果是边缘，添加轮廓颜色
    if (edgeFactor > 0.1) {
        vec4 outlineColor = vec4(0.0, 0.0, 0.0, 1.0);  // 黑色轮廓
        color = mix(color, outlineColor, 0.8);
    }
    
    float fogValue = smoothstep(FogStart, FogEnd, vertexDistance);
    fragColor = mix(color, FogColor, fogValue);
}
```

```glsl
#version 150

uniform sampler2D DiffuseSampler;

in vec2 texCoord;
out vec4 fragColor;

// 复古颜色矩阵
const vec4 RedMatrix   = vec4(0.393, 0.769, 0.189, 0.0);

const vec4 BlueMatrix  = vec4(0.272, 0.534, 0.131, 0.0);

void main() {
    vec4 color = texture(DiffuseSampler, texCoord);
    
    // 应用复古颜色矩阵
    fragColor = vec4(
        dot(color, RedMatrix),
        dot(color, GreenMatrix),
        dot(color, BlueMatrix),
        dot(color, AlphaMatrix)
    );
```

### 10.5 水面动画

让水面产生波浪效果。

```glsl
// rendertype_translucent.vsh - 波浪水面
#version 150

in vec3 Position;
in vec4 Color;
in vec2 UV0;
in vec2 UV2;
in vec3 Normal;

uniform mat4 ModelViewMat;
uniform mat4 ProjMat;
uniform float GameTime;
uniform vec3 ChunkOffset;

out vec4 vertexColor;
out vec2 texCoord;
out vec2 lightMapCoord;
out vec3 normal;
out float vertexDistance;

void main() {
    vec3 pos = Position + ChunkOffset;
    
    // 仅对水面（Y坐标较高）应用波浪
    if (Normal.y > 0.9) {  // 顶部法线
        float wave1 = sin(pos.x * 0.5 + GameTime * 200.0) * 0.02;
        float wave2 = sin(pos.z * 0.3 + GameTime * 150.0) * 0.02;
        float wave3 = sin((pos.x + pos.z) * 0.4 + GameTime * 180.0) * 0.01;
        pos.y += wave1 + wave2 + wave3;
    }
    
    gl_Position = ProjMat * ModelViewMat * vec4(pos, 1.0);
    vertexColor = Color;
    texCoord = UV0;
    lightMapCoord = UV2;
    normal = Normal;
    vertexDistance = length((ModelViewMat * vec4(pos, 1.0)).xyz);
}
```

## 11. 调试与排错

### 11.1 常见错误及解决

#### 错误：着色器编译失败

**症状**：游戏崩溃或显示紫色/黑色纹理

**检查方法**：
1. 查看游戏日志（`logs/latest.log`）
2. 搜索 `Shader compilation error` 或 `GLSL`
3. 日志会显示具体的错误行号和描述

**常见编译错误**：

```glsl
// 错误1：缺少版本声明
// 修复：在文件第一行添加
#version 150

// 错误2：使用了未声明的变量
vec4 color = texture(Sampler0, texCoord);  // 如果 Sampler0 未声明
// 修复：确保使用正确的 Uniform 名称

// 错误3：类型不匹配
vec3 color = texture(Sampler0, texCoord);  // texture 返回 vec4
// 修复：
vec4 texColor = texture(Sampler0, texCoord);
vec3 color = texColor.rgb;

// 错误4：精度问题（OpenGL ES）
// 在桌面 OpenGL 中不需要精度声明，但某些着色器可能需要
precision highp float;

// 错误5：版本不兼容
#version 120  // OpenGL 2.1
// vs
#version 150  // OpenGL 3.2（Minecraft 1.17+）
```

#### 错误：纹理显示为紫色/黑色

**原因**：纹理采样器未正确绑定或纹理坐标错误

```glsl
// 检查纹理坐标范围
if (texCoord.x < 0.0 || texCoord.x > 1.0 || 
    texCoord.y < 0.0 || texCoord.y > 1.0) {
    // 纹理坐标超出范围
    fragColor = vec4(1.0, 0.0, 1.0, 1.0);  // 紫色标记
    return;
}

// 检查纹理采样
vec4 texColor = texture(Sampler0, texCoord);
if (texColor == vec4(0.0)) {
    // 纹理可能未加载
    fragColor = vec4(1.0, 0.0, 0.0, 1.0);  // 红色标记
    return;
}
```

## 12. 最佳实践

### 12.1 性能优化

```glsl
// 1. 避免在片段着色器中进行复杂计算
// 不好的做法
for (int i = 0; i < 100; i++) {
    // 复杂循环
}

// 好的做法：使用预计算或查找表

// 2. 使用适当的精度
// 对于不需要高精度的计算，可以使用 mediump（OpenGL ES）
// 在桌面 OpenGL 中，默认都是 highp

// 3. 尽早丢弃片段
if (color.a < 0.1) {
    discard;  // 尽早退出，避免后续计算
}

// 4. 避免动态分支
// 不好的做法
if (someCondition) {
    // 复杂计算 A
} else {
    // 复杂计算 B
}

// 好的做法：使用 mix() 和 step()
float factor = step(threshold, value);
vec3 result = mix(colorA, colorB, factor);

// 5. 使用内置函数而非手写
// 不好的做法
float myLength = sqrt(x*x + y*y + z*z);

// 好的做法
float myLength = length(vec3(x, y, z));
```
