### 2.7 `assets/<命名空间>/lang/` —— 语言文件

**功能定位**：定义翻译文本，将本地化键名映射为实际显示的字符串。

**格式要求**：JSON 文件，以语言代码命名（如 `en_us.json`、`zh_cn.json`）。

```json
{
  "block.minecraft.stone": "石头",
  "item.minecraft.diamond": "钻石"
}
```

**游戏处理逻辑**：

1. 加载顺序：上层包覆盖下层包的相同键。
2. 不必提供完整键集，只覆盖需要的键即可。
3. 缺失的键会回退到下层包，最后显示键名本身。
4. 添加新语言需在 `pack.mcmeta` 中注册。

**键排除与替换**：

游戏内置 `deprecated.json` 标记弃用键和重命名键。此文件不可被资源包覆盖。

**样本包中的体现**：

1. `Chat_Reporting_Helper/assets/fo/lang/`：29 个语言文件，全面覆盖聊天举报相关文本。
2. `meme.teahouse.team-da0c28/assets/minecraft/lang/zh_meme.json`：7734 行，全面改写原版文本为梗化表达。

**注意事项**：

1. `%f`、`%d` 会被自动替换为 `%s`。
2. `%%` 和 `%s` 是实际起效的格式化符号。
3. 不支持的格式会产生 `TranslatableFormatException`。
