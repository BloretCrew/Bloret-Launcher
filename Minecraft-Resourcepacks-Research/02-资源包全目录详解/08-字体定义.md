### 2.8 `assets/<namespace>/font/` —— 字体定义

**功能定位**：定义自定义字体、字形映射、字体提供者。

**格式要求**：`default.json` 或其他 JSON 文件。

**提供者类型**：

| 类型 | 作用 |
|---|---|
| `bitmap` | 位图字体，将 PNG 贴图映射到 Unicode 字符 |
| `ttf` | TrueType 字体文件 |
| `space` | 调整字符间距 |
| `reference` | 引用其他字体定义 |
| `unihex` | 使用 `.hex` 格式的字形数据 |
| `legacy_unicode` | 旧版 Unicode 兼容 |

**游戏处理逻辑**：

1. `providers` 数组定义多个字体来源。
2. 按数组顺序查找字符。
3. 位图字体可精确控制每个字符的渲染。

**样本包中的体现**：

1. `meme.teahouse.team-da0c28/assets/minecraft/font/default.json`：4705 行的巨大字体定义文件。
2. 通过 `bitmap` 类型将大量自定义 PNG 字形映射到扩展 Unicode 字符。
3. 配合 `extb-*`、`extc-supp`、`glyph_sizes.bin` 等资源支持生僻汉字的渲染。
