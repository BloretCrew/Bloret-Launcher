### 2.1 根目录文件

#### `pack.mcmeta`

**功能定位**：资源包的"身份证"和"说明书"。

**格式要求**：JSON 格式，根对象必须包含 `pack` 字段。

```json
{
  "pack": {
    "pack_format": 64,
    "min_format": 34,
    "max_format": 64,
    "description": "示例包",
    "supported_formats": [34, 64]
  }
}
```

**关键字段**：

| 字段 | 必填 | 作用 |
|---|---|---|
| `pack.pack_format` | 是 | 资源包格式主版本号 |
| `pack.description` | 是 | 资源包描述文本，支持格式化代码 |
| `pack.min_format` | 否 | 兼容的最低格式版本 |
| `pack.max_format` | 否 | 兼容的最高格式版本 |
| `pack.supported_formats` | 否 | 兼容区间，可写数组或对象 |
| `language.<code>` | 否 | 注册新语言，含 `name`、`region`、`bidirectional` |
| `overlays` | 否 | 叠加目录定义，用于同一包适配多版本 |
| `filter` | 否 | 按命名空间和正则过滤低优先级资源 |

**游戏处理逻辑**：

1. 游戏启动时扫描此文件。
2. `pack_format` 不匹配 → 显示版本错误，包可能被忽略。
3. 描述支持 `§` 格式化代码。
4. `language` 注册后需在对应 `lang/` 目录提供同名语言文件。
5. `overlays` 可使同一包对不同版本提供不同资源。

**样本包中的体现**：

1. `Better-Leaves-9.5/pack.mcmeta`：格式 15，兼容区间 [15, 255]。
2. `FreshAnimations_v1.10.5/pack.mcmeta`：min_format 84, max_format 999，说明面向极新版本。
3. `meme.teahouse.team-da0c28/pack.mcmeta`：定义了 `zh_meme` 语言，含语言名称和地区。
4. `Chat_Reporting_Helper/pack.mcmeta`：使用 `translate` 键做描述，体现国际化风格。

#### `pack.png`

**功能定位**：资源包图标。

**格式要求**：`png` 文件，推荐 128×128 或正方形。

**游戏处理逻辑**：

1. 在资源包列表中渲染。
2. 缺失时使用默认的 `unknown_pack.png`。
3. 图标会被分配命名空间 ID 用于导出。

**样本包中的体现**：五个包全部包含此文件。
