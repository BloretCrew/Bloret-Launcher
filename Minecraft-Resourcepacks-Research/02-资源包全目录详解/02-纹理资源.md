### 2.2 `assets/<命名空间>/textures/` —— 纹理资源

**功能定位**：最核心的资源类型之一，控制方块、物品、实体、GUI、粒子等几乎所有视觉元素的贴图。

**格式要求**：`.png` 文件，推荐 16×16（原版风格）或更高分辨率。

**子目录结构**（原版 `minecraft` 命名空间）：

| 子目录 | 功能 |
|---|---|
| `textures/block/` | 方块贴图 |
| `textures/item/` | 物品贴图 |
| `textures/entity/` | 实体贴图 |
| `textures/gui/` | GUI 界面贴图 |
| `textures/misc/` | 杂项贴图（如附魔闪光） |
| `textures/particle/` | 粒子贴图 |
| `textures/font/` | 字体字形贴图 |
| `textures/map/` | 地图相关贴图 |
| `textures/painting/` | 画作贴图 |
| `textures/environment/` | 环境贴图（如云、太阳、月亮） |
| `textures/models/` | 模型专用贴图 |
| `textures/mob_effect/` | 状态效果图标 |
| `textures/trims/` | 盔甲纹饰贴图 |

**游戏处理逻辑**：

1. 游戏通过模型引用贴图路径（如 `minecraft:block/stone`）。
2. 贴图被烘焙到纹理图集中，避免频繁绑定。
3. 高层资源包的同路径贴图替换低层。
4. 元数据文件（`.mcmeta`）可控制贴图动画和插值。

**特殊机制：`.png.mcmeta` 贴图元数据**

可用于定义：

1. 多帧动画。如 `water_still.png.mcmeta`、`lava_flow.png.mcmeta`。
2. 插值行为。控制帧间是否平滑过渡。

**样本包中的体现**：

1. `MandalasGUI+Dakmode_1.21.6_v2.1`：覆盖大量 `textures/gui/` 和 `textures/item/`。
2. `FreshAnimations_v1.10.5`：覆盖大量 `textures/entity/`。
3. `meme.teahouse.team-da0c28`：覆盖 `textures/block/`、`textures/misc/`、`textures/font/`。
4. `Better-Leaves-9.5`：覆盖 `textures/block/` 中的特定叶子贴图。
