# 资源包发布与分发指南

## 1. 发布准备

### 1.1 版本号确认
- 使用语义化版本
- 更新pack.mcmeta中的版本信息
- 记录版本变更

### 1.2 pack.mcmeta检查
- 设置正确的pack_format
- 编写清晰的描述
- 检查支持的版本范围

```json
{
  "pack": {
    "pack_format": 34,
    "supported_formats": [34, 45],
    "description": "§aMy Resource Pack §ev1.0.0"
  }
}
```

### 1.3 pack.png制作
- 推荐尺寸：128x128或256x256
- PNG格式
- 清晰展示资源包特色

### 1.4 README.md编写
- 包说明
- 安装指南
- 版本历史
- 联系方式
- 许可证信息

### 1.5 LICENSE选择
- **MIT**：宽松许可
- **CC BY-SA**：署名-相同方式共享
- **CC BY-NC-SA**：署名-非商业性-相同方式共享
- **All Rights Reserved**：保留所有权利

## 2. 打包和压缩

### 2.1 ZIP压缩设置
- 使用标准ZIP格式
- 选择适当的压缩级别
- 确保文件结构正确

### 2.2 文件组织
- 确保pack.mcmeta在根目录
- 确保assets/目录结构正确
- 移除不必要的文件

### 2.3 压缩级别选择
- **存储**：不压缩，快速
- **低压缩**：快速压缩
- **标准压缩**：平衡
- **高压缩**：最小文件，较慢
