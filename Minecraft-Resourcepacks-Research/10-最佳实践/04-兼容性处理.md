# 资源包兼容性处理

## 1. 兼容性类型

### 1.1 版本兼容性
- 不同Minecraft版本之间的兼容
- pack_format版本号
- 资源格式变更

### 1.2 模组兼容性
- 与Forge/Fabric模组的兼容
- 与OptiFine/Sodium渲染模组的兼容
- 模组添加的方块/物品

### 1.3 客户端兼容性
- 原版客户端
- OptiFine客户端
- Sodium/Iris客户端
- 其他渲染模组

### 1.4 服务器兼容性
- 服务器资源包
- 强制资源包
- 可选资源包

## 2. 版本兼容性处理

### 2.1 使用supported_formats
```json
{
  "pack": {
    "pack_format": 34,
    "supported_formats": [34, 45]
  }
}
```

### 2.2 使用覆盖层系统
```
ResourcePack/
├── assets/
├── overlay_22-43/
│   └── assets/
├── overlay_22-46/
│   └── assets/
└── overlay_22-54/
    └── assets/
```

### 2.3 版本检测和条件加载
- 使用覆盖层系统
- 根据pack_format加载不同资源
- 支持多版本

### 2.4 多版本分支维护
- 维护多个版本的资源包
- 使用版本控制系统
- 自动化构建

## 3. 模组兼容性处理

### 3.1 命名空间机制
- 使用模组的命名空间
- 避免命名冲突
- 正确引用模组资源

### 3.2 OptiFine扩展兼容
- **CEM**：自定义实体模型
- **CIT**：自定义物品纹理
- **CTM**：连接纹理
- **RandomEntities**：随机实体
- **BetterGrass**：更好的草地

### 3.3 Forge/Fabric兼容
- 使用正确的命名空间
- 遵循模组资源加载规则
- 测试不同模组组合

### 3.4 常见模组兼容
- **JEI/REI**：物品列表
- **Create**：机械模组
- **Applied Energistics**：存储模组
- **Botania**：魔法模组

## 4. 客户端兼容性

### 4.1 原版客户端
- 确保基本功能正常
- 避免依赖特定模组
- 测试原版加载

### 4.2 OptiFine客户端
- 支持OptiFine扩展
- 测试CEM/CIT/CTM
- 处理OptiFine特定功能

### 4.3 Sodium/Iris客户端
- 测试渲染兼容性
- 避免OptiFine特有功能
- 使用通用方法

### 4.4 其他渲染模组
- 测试不同渲染模组
- 避免冲突
- 提供兼容性说明

## 5. 服务器兼容性

### 5.1 服务器资源包
- 支持服务器强制资源包
- 处理资源包冲突
- 提供可选资源包

### 5.2 强制资源包
- 服务器可以强制加载资源包
- 玩家无法禁用
- 需要确保兼容性

### 5.3 可选资源包
- 玩家可以选择加载
- 提供说明文档
- 处理冲突情况
