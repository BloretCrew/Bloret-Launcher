# 目录结构最佳实践

## 1. 标准目录结构

### 1.1 推荐的顶层结构
```
ResourcePack/
├── pack.mcmeta          # 资源包元数据
├── pack.png             # 资源包图标
├── README.md            # 说明文档
├── LICENSE              # 许可证
└── assets/
    ├── minecraft/       # 原版资源
    └── mynamespace/     # 自定义命名空间
```

### 1.2 assets/目录组织
```
assets/
├── minecraft/
│   ├── textures/
│   │   ├── block/
│   │   ├── item/
│   │   ├── entity/
│   │   ├── gui/
│   │   └── particle/
│   ├── models/
│   │   ├── block/
│   │   └── item/
│   ├── blockstates/
│   ├── sounds/
│   ├── lang/
│   ├── font/
│   ├── shaders/
│   └── particles/
└── mynamespace/
    └── ...
```

### 1.3 命名空间划分
- `minecraft`：原版资源覆盖
- 自定义命名空间：新添加的资源
- 模组命名空间：模组兼容资源

## 2. 命名空间策略

### 2.1 使用minecraft命名空间
- 覆盖原版资源
- 替换原版纹理、模型、声音等
- 修改原版行为

### 2.2 使用自定义命名空间
- 添加新资源
- 避免与原版冲突
- 便于管理和维护

### 2.3 多命名空间组织
- 按功能分组
- 按模组分组
- 按类型分组

## 3. 资源分类组织

### 3.1 textures/目录组织
```
textures/
├── block/           # 方块纹理
├── item/            # 物品纹理
├── entity/          # 实体纹理
│   ├── villager/
│   ├── zombie/
│   └── ...
├── gui/             # GUI纹理
│   ├── widgets.png
│   ├── icons.png
│   └── container/
├── particle/        # 粒子纹理
├── environment/     # 环境纹理
├── font/            # 字体纹理
└── misc/            # 其他纹理
```

### 3.2 models/目录组织
```
models/
├── block/           # 方块模型
├── item/            # 物品模型
└── entity/          # 实体模型（OptiFine CEM）
```

### 3.3 sounds/目录组织
```
sounds/
├── mob/             # 生物声音
├── block/           # 方块声音
├── item/            # 物品声音
├── ambient/         # 环境声音
├── music/           # 音乐
└── weather/         # 天气声音
```

### 3.4 lang/目录组织
```
lang/
├── en_us.json       # 英语
├── zh_cn.json       # 中文
├── zh_meme.json     # 梗体中文
└── ...
```

## 8. 常见目录结构问题和解决方案

### 8.1 目录层级过深
- **问题**：目录层级过深导致路径过长
- **解决方案**：合理组织目录，避免过深嵌套

### 8.2 文件混放
- **问题**：不同类型的文件混放在同一目录
- **解决方案**：按类型和功能分类存放

### 8.3 命名空间混乱
- **问题**：命名空间使用混乱
- **解决方案**：统一命名空间策略

### 8.4 缺少文档
- **问题**：缺少README和LICENSE
- **解决方案**：添加必要的文档文件
