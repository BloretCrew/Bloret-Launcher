# Minecraft 模型包开发指南

## 一、模型系统概述

### 1.1 模型系统架构

Minecraft 的模型系统是一个层级化的 JSON 驱动系统，通过继承和组合机制实现复杂的几何体定义：

```
模型系统层级结构：
├── 方块模型（Block Models）
│   ├── 基础几何体定义
│   ├── 纹理变量绑定
│   └── 显示参数配置
├── 物品模型（Item Models）
│   ├── 生成模型（generated）
│   ├── 手持模型（handheld）
│   └── 自定义几何体
├── 方块状态（Blockstates）
│   ├── 变体（variants）
│   └── 多部分（multipart）
└── 实体模型（Entity Models）
    ├── OptiFine CEM 格式
    └── 基岩版格式
```

### 1.2 模型文件路径

```
模型文件路径规范：
assets/[namespace]/
├── models/
│   ├── block/           # 方块模型
│   │   ├── stone.json
│   │   ├── dirt.json
│   │   └── ...
│   ├── item/            # 物品模型
│   │   ├── diamond_sword.json
│   │   ├── bow.json
│   │   └── ...
│   └── entity/          # 实体模型（非标准）
├── blockstates/         # 方块状态
│   ├── stone.json
│   ├── oak_log.json
│   └── ...
└── optifine/            # OptiFine 专用
    └── cem/             # 自定义实体模型
        ├── zombie.jem
        └── creeper.jem
```

### 1.3 命名空间

```
命名空间说明：
├── minecraft：原版游戏资源
│   └── 所有原版方块、物品、实体
├── modid：Mod 资源
│   └── 每个 Mod 有独立命名空间
└── 自定义命名空间
    └── 资源包可以定义新的命名空间

路径示例：
assets/minecraft/models/block/stone.json        # 原版石头模型
assets/create/models/block/andesite_casing.json  # Create Mod 模型
assets/mypack/models/block/custom_block.json     # 自定义命名空间
```

## 二、方块模型开发

### 2.1 JSON 语法基础

方块模型使用标准 JSON 格式，包含以下核心字段：

```json
{
  "parent": "minecraft:block/cube_all",
  "textures": {
    "all": "minecraft:block/stone"
  },
  "elements": [],
  "display": {},
  "gui_light": "front",
  "ambientocclusion": true
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| parent | string | 父模型，继承其属性 |
| textures | object | 纹理变量映射 |
| elements | array | 几何体元素列表 |
| display | object | 显示位置参数 |
| gui_light | string | GUI 光照模式 |
| ambientocclusion | boolean | 是否启用环境光遮蔽 |

### 2.2 元素（Elements）详解

元素是模型的基本几何体单位，定义了 3D 空间中的立方体：

```json
{
  "elements": [
    {
      "comment": "主体部分",
      "from": [0, 0, 0],
      "to": [16, 16, 16],
      "rotation": {
        "origin": [8, 8, 8],
        "axis": "y",
        "angle": 45,
        "rescale": true
      },
      "shade": true,
      "faces": {
        "down": {
          "texture": "#bottom",
          "uv": [0, 0, 16, 16],
          "cullface": "down",
          "tintindex": 0
        },
        "up": {
          "texture": "#top",
          "uv": [0, 0, 16, 16],
          "cullface": "up"
        },
        "north": {
          "texture": "#north",
          "uv": [0, 0, 16, 16],
          "cullface": "north"
        },
        "south": {
          "texture": "#south",
          "uv": [0, 0, 16, 16],
          "cullface": "south"
        },
        "west": {
          "texture": "#west",
          "uv": [0, 0, 16, 16],
          "cullface": "west"
        },
        "east": {
          "texture": "#east",
          "uv": [0, 0, 16, 16],
          "cullface": "east"
        }
      }
    }
  ]
}
```

**from 和 to 字段**：

```
坐标系统：
├── X 轴：东西方向（东为正）
├── Y 轴：上下方向（上为正）
├── Z 轴：南北方向（南为正）
├── 范围：-16 到 32（标准游戏单位）
└── 原点：方块西北下角

常见坐标示例：
├── 完整方块：[0,0,0] 到 [16,16,16]
├── 半砖（下半）：[0,0,0] 到 [16,8,16]
├── 半砖（上半）：[0,8,0] 到 [16,16,16]
├── 台阶：[0,0,0] 到 [16,8,8]
└── 楼梯：[0,0,0] 到 [16,8,16] + 旋转

注意事项：
├── 坐标必须在 -16 到 32 范围内
├── from 的每个分量必须小于 to
├── 超出 0-16 的部分需要特殊处理
└── 小于 1/16 的尺寸可能导致渲染问题
```

**rotation 字段**：

```json
{
  "rotation": {
    "origin": [8, 8, 8],
    "axis": "y",
    "angle": 45,
    "rescale": false
  }
}

// rotation 字段说明：
// origin: 旋转中心点 [x, y, z]
// axis: 旋转轴（"x", "y", "z"）
// angle: 旋转角度（-45, -22.5, 0, 22.5, 45）
// rescale: 是否缩放旋转后的元素

// 有效角度值：
// -45: 逆时针 45 度
// -22.5: 逆时针 22.5 度
// 0: 不旋转
// 22.5: 顺时针 22.5 度
// 45: 顺时针 45 度
```

**faces 字段**：

```json
{
  "faces": {
    "north": {
      "texture": "#texture_variable",
      "uv": [0, 0, 16, 16],
      "cullface": "north",
      "rotation": 0,
      "tintindex": -1
    }
  }
}

// faces 字段说明：
// 方向键：down, up, north, south, west, east
// texture: 纹理变量引用（以 # 开头）
// uv: UV 坐标 [u1, v1, u2, v2]
// cullface: 隐藏面（相邻方块为不透明时隐藏）
// rotation: 纹理旋转（0, 90, 180, 270）
// tintindex: 颜色索引（用于生物群落颜色）

// UV 坐标说明：
// [0, 0, 16, 16] 表示整个纹理
// [0, 0, 8, 8] 表示左上角四分之一
// UV 坐标范围：0-16（对应纹理像素）
```

### 2.3 纹理变量

纹理变量允许在模型中定义可替换的纹理引用：

```json
{
  "textures": {
    // 基础变量
    "all": "minecraft:block/stone",
    "top": "minecraft:block/stone_top",
    "bottom": "minecraft:block/stone_bottom",
    "side": "minecraft:block/stone_side",

    // 变量引用
    "particle": "#side",
    "north": "#side",
    "south": "#side",
    "east": "#side",
    "west": "#side",

    // 父模型变量
    "up": "#top",
    "down": "#bottom"
  }
}

// 纹理变量规则：
// 1. 变量名不以 # 开头
// 2. 引用变量时需要 # 前缀
// 3. 变量值可以是完整路径或另一个变量引用
// 4. 纹理路径格式：namespace:path/to/texture
// 5. 可以省略 minecraft: 命名空间前缀
```

**纹理变量继承**：

```json
// 父模型
// 文件路径：assets/minecraft/models/block/cube_column.json
{
  "textures": {
    "end": "#top",
    "side": "#side"
  },
  "elements": [
    {
      "from": [0, 0, 0],
      "to": [16, 16, 16],
      "faces": {
        "down": {"texture": "#end", "cullface": "down"},
        "up": {"texture": "#end", "cullface": "up"},
        "north": {"texture": "#side", "cullface": "north"},
        "south": {"texture": "#side", "cullface": "south"},
        "west": {"texture": "#side", "cullface": "west"},
        "east": {"texture": "#side", "cullface": "east"}
      }
    }
  ]
}

// 子模型
// 文件路径：assets/minecraft/models/block/oak_log.json
{
  "parent": "minecraft:block/cube_column",
  "textures": {
    "top": "minecraft:block/oak_log_top",
    "side": "minecraft:block/oak_log"
  }
}
```

### 2.4 显示参数（Display）

显示参数控制模型在不同场景中的渲染方式：

```json
{
  "display": {
    "thirdperson_righthand": {
      "rotation": [75, 45, 0],
      "translation": [0, 2.5, 0],
      "scale": [0.375, 0.375, 0.375]
    },
    "thirdperson_lefthand": {
      "rotation": [75, 45, 0],
      "translation": [0, 2.5, 0],
      "scale": [0.375, 0.375, 0.375]
    },
    "firstperson_righthand": {
      "rotation": [0, 45, 0],
      "translation": [0, 0, 0],
      "scale": [0.4, 0.4, 0.4]
    },
    "firstperson_lefthand": {
      "rotation": [0, 225, 0],
      "translation": [0, 0, 0],
      "scale": [0.4, 0.4, 0.4]
    },
    "gui": {
      "rotation": [30, 45, 0],
      "translation": [0, 0, 0],
      "scale": [0.625, 0.625, 0.625]
    },
    "head": {
      "rotation": [0, 0, 0],
      "translation": [0, 0, 0],
      "scale": [1, 1, 1]
    },
    "ground": {
      "rotation": [0, 0, 0],
      "translation": [0, 3, 0],
      "scale": [0.25, 0.25, 0.25]
    },
    "fixed": {
      "rotation": [0, 0, 0],
      "translation": [0, 0, 0],
      "scale": [0.5, 0.5, 0.5]
    }
  }
}

// 显示位置说明：
// thirdperson_righthand: 第三人称右手
// thirdperson_lefthand: 第三人称左手
// firstperson_righthand: 第一人称右手
// firstperson_lefthand: 第一人称左手
// gui: 物品栏界面
// head: 头盔显示
// ground: 掉落物显示
// fixed: 物品展示框

// 参数说明：
// rotation: [x, y, z] 旋转角度
// translation: [x, y, z] 平移量
// scale: [x, y, z] 缩放比例
```

## 三、物品模型开发

### 3.1 物品模型继承

物品模型通常继承自基础父模型：

```json
// 标准物品模型（生成类）
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "minecraft:item/diamond_sword"
  }
}

// 手持物品模型（工具类）
{
  "parent": "minecraft:item/handheld",
  "textures": {
    "layer0": "minecraft:item/diamond_pickaxe"
  }
}

// generated 和 handheld 的区别：
// generated - 扁平化渲染，适合大多数物品
// handheld - 手持渲染，适合工具和武器
```

### 3.2 多层纹理

物品支持多层纹理叠加：

```json
// 多层纹理示例 - 附魔金苹果
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "minecraft:item/apple",
    "layer1": "minecraft:item/golden_apple"
  }
}

// 多层纹理示例 - 皮革胸甲
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "minecraft:item/leather_chestplate",
    "layer1": "minecraft:item/leather_chestplate_overlay"
  }
}

// 层级说明：
// layer0: 基础层（最底层）
// layer1: 叠加层
// layer2: 更多层
// ...
// 每层可以独立染色
```

### 3.3 模型覆盖（Overrides）

模型覆盖允许根据物品状态动态切换模型：

```json
// 弓的模型覆盖示例
// 文件路径：assets/minecraft/models/item/bow.json
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "minecraft:item/bow_standby"
  },
  "display": {
    "thirdperson_righthand": {
      "rotation": [-80, 260, -40],
      "translation": [-1, -2, 2.5],
      "scale": [0.9, 0.9, 0.9]
    },
    "thirdperson_lefthand": {
      "rotation": [-80, -280, 40],
      "translation": [-1, -2, 2.5],
      "scale": [0.9, 0.9, 0.9]
    },
    "firstperson_righthand": {
      "rotation": [0, -90, 25],
      "translation": [1.13, 3.2, 1.13],
      "scale": [0.68, 0.68, 0.68]
    },
    "firstperson_lefthand": {
      "rotation": [0, 90, -25],
      "translation": [1.13, 3.2, 1.13],
      "scale": [0.68, 0.68, 0.68]
    }
  },
  "overrides": [
    {
      "predicate": {"pulling": 1},
      "model": "minecraft:item/bow_pulling_0"
    },
    {
      "predicate": {"pulling": 1, "pull": 0.65},
      "model": "minecraft:item/bow_pulling_1"
    },
    {
      "predicate": {"pulling": 1, "pull": 0.9},
      "model": "minecraft:item/bow_pulling_2"
    }
  ]
}
```

**常用覆盖谓词**：

```json
// 常用 predicate 字段：
{
  "overrides": [
    // 损坏程度（0.0 - 1.0）
    {"predicate": {"damage": 0.5}, "model": "item/damaged"},

    // 是否正在使用
    {"predicate": {"using": 1}, "model": "item/using"},

    // 拉弓状态（0.0 - 1.0）
    {"predicate": {"pulling": 1, "pull": 0.5}, "model": "item/pulling"},

    // 盾牌阻挡
    {"predicate": {"blocking": 1}, "model": "item/blocking"},

    // 钓鱼竿抛出
    {"predicate": {"cast": 1}, "model": "item/cast"},

    // 时钟时间
    {"predicate": {"time": 0.5}, "model": "item/time"},

    // 指南针方向
    {"predicate": {"angle": 0.5}, "model": "item/angle"},

    // 自定义模型数据（用于自定义物品）
    {"predicate": {"custom_model_data": 1}, "model": "item/custom_1"}
  ]
}
```

**自定义模型数据覆盖**：

```json
// 使用 custom_model_data 实现多个物品模型
// 文件路径：assets/minecraft/models/item/diamond_sword.json
{
  "parent": "minecraft:item/handheld",
  "textures": {
    "layer0": "minecraft:item/diamond_sword"
  },
  "overrides": [
    {
      "predicate": {"custom_model_data": 1},
      "model": "minecraft:item/diamond_sword_fire"
    },
    {
      "predicate": {"custom_model_data": 2},
      "model": "minecraft:item/diamond_sword_ice"
    },
    {
      "predicate": {"custom_model_data": 3},
      "model": "minecraft:item/diamond_sword_lightning"
    }
  ]
}

// 火焰钻石剑模型
// 文件路径：assets/minecraft/models/item/diamond_sword_fire.json
{
  "parent": "minecraft:item/handheld",
  "textures": {
    "layer0": "minecraft:item/diamond_sword_fire"
  }
}
```

### 3.4 自定义物品几何体

物品模型也可以包含自定义几何体：

```json
// 自定义物品几何体示例 - 3D 书籍
{
  "parent": "minecraft:item/generated",
  "textures": {
    "cover": "minecraft:item/custom_book_cover",
    "pages": "minecraft:item/custom_book_pages",
    "spine": "minecraft:item/custom_book_spine",
    "particle": "#cover"
  },
```

## 四、方块状态（Blockstates）

### 4.1 变体（Variants）系统

变体系统根据方块状态属性选择不同的模型：

```json
// 文件路径：assets/minecraft/blockstates/oak_log.json

// 变体说明：
// axis=x: X 轴方向（东西向）
// axis=y: Y 轴方向（上下向，默认）

// 旋转参数：
```

### 4.2 多部分（Multipart）系统

Multipart 系统更灵活，允许根据多个状态组合应用不同模型：

```json
// 文件路径：assets/minecraft/blockstates/oak_fence.json
{
  "multipart": [
    {
      "apply": {
        "model": "minecraft:block/oak_fence_post"
      }
    },
    {
      "when": {
        "north": "true"
      },
      "apply": {
        "model": "minecraft:block/oak_fence_side",
        "uvlock": true
      }
    },
    {
      "when": {
        "east": "true"
      },
      "apply": {
        "model": "minecraft:block/oak_fence_side",
        "y": 90,
        "uvlock": true
      }
    },
    {
      "when": {
        "south": "true"
      },
      "apply": {
        "model": "minecraft:block/oak_fence_side",
        "y": 180,
        "uvlock": true
      }
    },
    {
      "when": {
        "west": "true"
      },
      "apply": {
        "model": "minecraft:block/oak_fence_side",
        "y": 270,
        "uvlock": true
      }
    }
  ]
}

// multipart 说明：
// 1. 第一个 apply 无条件应用（栅栏柱）
// 2. 后续 apply 根据条件应用（栅栏连接）
// 3. uvlock: true 锁定 UV 坐标，避免纹理旋转
```

**条件组合**：

```json
// 复杂条件示例
{
  "multipart": [
    {
      "when": {
        "AND": [
          {"north": "true"},
          {"south": "false"}
        ]
      },

        "model": "minecraft:block/fence_side_north"
      }
    },

          {"west": "true"}
        ]
      },
      "apply": {
        "model": "minecraft:block/fence_side_east_west"
      }
    }
  ]
}

// 条件运算符：
// AND: 所有条件都满足
// OR: 任一条件满足
// NOT: 条件不满足
// 嵌套使用：可以组合多个运算符
```

### 7.2 模型验证工具

```json
// 使用 JSON 验证脚本检查模型文件
// validate_model.py

import json
import sys

def validate_model(file_path):
    """验证模型 JSON 文件"""
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            model = json.load(f)

        errors = []

        # 检查必需字段
        if 'parent' not in model and 'elements' not in model:
            errors.append("缺少 parent 或 elements 字段")

        # 检查 textures 字段
        if 'textures' in model:
            for key, value in model['textures'].items():
                if not isinstance(value, str):
                    errors.append(f"纹理变量 {key} 的值必须是字符串")

        # 检查 elements 字段
        if 'elements' in model:
            for i, element in enumerate(model['elements']):
                if 'from' not in element:
                    errors.append(f"元素 {i} 缺少 from 字段")
                if 'to' not in element:
                    errors.append(f"元素 {i} 缺少 to 字段")
                if 'faces' not in element:
                    errors.append(f"元素 {i} 缺少 faces 字段")

                # 检查坐标范围
                if 'from' in element and 'to' in element:
                    from_pos = element['from']
                    to_pos = element['to']
                    for j in range(3):
                        if from_pos[j] < -16 or from_pos[j] > 32:
                            errors.append(f"元素 {i} 的 from 坐标超出范围")
                        if to_pos[j] < -16 or to_pos[j] > 32:
                            errors.append(f"元素 {i} 的 to 坐标超出范围")

        # 检查 display 字段
        if 'display' in model:
            valid_positions = [
                'thirdperson_righthand', 'thirdperson_lefthand',
                'firstperson_righthand', 'firstperson_lefthand',
                'gui', 'head', 'ground', 'fixed'
            ]
            for position in model['display']:
                if position not in valid_positions:
                    errors.append(f"未知的显示位置: {position}")

        if errors:
            print(f"验证失败 {file_path}:")
            for error in errors:
                print(f"  - {error}")
            return False
        else:
            print(f"验证通过: {file_path}")
            return True

    except json.JSONDecodeError as e:
        print(f"JSON 语法错误 {file_path}: {e}")
        return False
    except Exception as e:
        print(f"验证错误 {file_path}: {e}")
        return False

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("使用方法: python validate_model.py <model_file.json>")
        sys.exit(1)

    file_path = sys.argv[1]
    if validate_model(file_path):
        sys.exit(0)
    else:
        sys.exit(1)
```

## 十、常见问题解决

### Q1：模型在游戏中显示不正确

```
排查步骤：
1. 检查 JSON 语法
   - 使用 JSON 验证工具
   - 检查引号和逗号

2. 检查纹理路径
   - 确保纹理文件存在
   - 检查路径格式

3. 检查坐标范围
   - from/to 坐标在 -16 到 32 之间
   - 确保 from < to

4. 检查父模型
   - 确保父模型存在
   - 检查继承关系

5. 重新加载资源包
   - 按 F3 + T 重新加载
   - 检查控制台错误
```

### Q2：方块状态不生效

```
排查步骤：
1. 检查方块状态文件
   - 确保文件名与方块 ID 匹配
   - 检查 JSON 语法

2. 检查状态属性
   - 确保属性名正确
   - 检查属性值格式

3. 检查模型引用
   - 确保模型文件存在
   - 检查路径格式

4. 测试不同状态
   - 使用调试命令查看状态
   - 检查所有可能的状态组合
```

### Q3：实体模型不显示

```
排查步骤：
1. 检查文件路径
   - 确保在 optifine/cem/ 目录
   - 检查文件扩展名 .jem

2. 检查纹理路径
   - 确保纹理文件存在
   - 检查纹理尺寸

3. 检查模型语法
   - 确保 JSON 格式正确
   - 检查必需字段

4. 安装 OptiFine
   - CEM 需要 OptiFine 支持
   - 确保 OptiFine 版本兼容
```
