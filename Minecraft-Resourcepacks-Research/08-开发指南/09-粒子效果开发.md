## 爆子系统概述

### 什么是粒子系统

Minecraft 的粒子系统（Particle System）是游戏中用于渲染各种视觉特效的核心组件。粒子是一种轻量级的视觉元素，它们以小型纹理精灵（Sprite）的形式出现在游戏世界中，用于模拟火焰、烟雾、水花、爆炸、附魔光效等各种自然现象和魔法效果。

粒子系统的核心特点包括：

- **轻量级渲染**：每个粒子只是一个面向摄像机的四边形（Billboard Quad），渲染开销极小
- **批量处理**：同类型的粒子通常批量渲染，减少绘制调用（Draw Call）
- **生命周期管理**：每个粒子有明确的生命周期，从创建到消亡自动管理
- **行为驱动**：粒子通过物理模拟或预定义行为运动，包括重力、风力、随机扩散等

### 粒子在资源包中的角色

在 Minecraft 资源包中，粒子系统主要涉及以下方面的自定义：

1. **粒子纹理**：自定义粒子的外观图像
2. **粒子定义**：通过 JSON 文件定义粒子的行为参数
3. **粒子配置**：修改已有粒子类型的颜色、大小、速度等属性

需要注意的是，Minecraft 的粒子系统在资源包层面的自定义能力相对有限。许多粒子行为是硬编码在游戏引擎中的，资源包主要能修改的是纹理和部分参数。对于更复杂的粒子效果，通常需要借助模组（如 Create、Particle API）来实现。

### 粒子渲染流程

Minecraft 粒子的渲染流程大致如下：

```
游戏逻辑触发粒子生成
    ↓
粒子系统创建粒子实例
    ↓
分配纹理（从粒子纹理表或独立纹理）
    ↓
设置初始参数（位置、速度、颜色、大小等）
    ↓
每帧更新粒子状态（位置、透明度、生命周期）
    ↓
面向摄像机渲染精灵
    ↓
生命周期结束，粒子移除
```

## 粒子纹理体系

### particles.png 精灵图集

Minecraft 使用一个名为 `particles.png` 的精灵图集（Sprite Atlas）来存储大量基础粒子的纹理。这个文件位于：

```
assets/minecraft/textures/particle/particles.png
```

`particles.png` 是一个 128x128 像素的纹理图集，被划分为 8x8 的网格，每个网格单元为 16x16 像素，共包含 64 个粒子子纹理。每个子纹理通过 UV 坐标索引访问。

图集布局如下（部分）：

```
行0: 粘液球  末影珍珠  火焰1  火焰2  水滴  灰烬  烟雾1  烟雾2
行1: 心形    音符      信标   诅咒    幽灵  白色   红色   蓝色
行2: 骨粉    向上粒子  向下   激活    附魔  附魔2  刮削  岩浆
行3: 小火焰  大火焰    红石   闪烁    旋转  弹跳  爆裂   海泡菜
...依此类推
```

#### 自定义 particles.png

资源包可以替换 `particles.png` 文件来修改粒子纹理。替换时需要注意：

1. **保持原始尺寸**：必须保持 128x128 像素，否则会导致 UV 坐标错位
2. **保持网格对齐**：每个子纹理必须精确对齐 16x16 的网格
3. **透明度支持**：粒子纹理支持 Alpha 通道，可以创建半透明效果

```json
// 注意：particles.png 是一个 PNG 图像文件，不是 JSON
// 替换路径：
// assets/minecraft/textures/particle/particles.png
```

### 独立粒子纹理文件

除了 `particles.png` 图集之外，Minecraft 还使用许多独立的粒子纹理文件，存储在：

常见的独立粒子纹理包括：


### 纹理格式要求

粒子纹理的格式要求：

| 属性 | 要求 |
|------|------|
| 格式 | PNG（推荐 32 位带 Alpha） |
| 尺寸 | 通常为 2 的幂次方（8x8, 16x16, 32x32） |
| 透明度 | 支持完全透明和半透明 |
| 颜色空间 | sRGB |
| 最大尺寸 | 建议不超过 64x64（性能考虑） |

## 粒子定义文件

### 粒子定义的 JSON 结构

从 Minecraft 1.20.5 开始，Minecraft 引入了基于 JSON 的粒子定义系统，允许数据包和资源包更精细地控制粒子行为。粒子定义文件位于：

```
assets/<namespace>/particles/<particle_name>.json
```

一个基本的粒子定义文件结构如下：

```json
{
  "textures": [
    "minecraft:generic_0",
    "minecraft:generic_1",
    "minecraft:generic_2",
    "minecraft:generic_3",
    "minecraft:generic_4",
    "minecraft:generic_5",
    "minecraft:generic_6",
    "minecraft:generic_7"
  ]
}
```

### 纹理引用

粒子定义中的 `textures` 字段是一个纹理标识符数组。每个标识符对应一个纹理文件：

```json
{
  "textures": [
    "mypack:custom_particle_0",
    "mypack:custom_particle_1",
    "mypack:custom_particle_2"
  ]
}
```

纹理标识符的解析规则：
- `minecraft:generic_0` 解析为 `assets/minecraft/textures/particle/generic_0.png`
- `mypack:custom_particle_0` 解析为 `assets/mypack/textures/particle/custom_particle_0.png`

### 帧动画配置

如果粒子包含多个纹理帧，可以通过帧配置控制动画：

```json
{
  "textures": [
    "minecraft:generic_0",
    "minecraft:generic_1",
    "minecraft:generic_2",
    "minecraft:generic_3",
    "minecraft:generic_4",
    "minecraft:generic_5",
    "minecraft:generic_6",
    "minecraft:generic_7"
  ]
}
```

粒子系统会按顺序循环播放这些帧，帧速率由粒子类型决定（通常是每帧 2-4 个游戏 tick）。

### 自定义粒子定义示例

创建一个自定义的魔法粒子效果：

```json
{
  "textures": [
    "mypack:magic_spark_0",
    "mypack:magic_spark_1",
    "mypack:magic_spark_2",
    "mypack:magic_spark_3"
  ]
}
```

对应的纹理文件需要放置在：

```
assets/mypack/textures/particle/
├── magic_spark_0.png
├── magic_spark_1.png
├── magic_spark_2.png
└── magic_spark_3.png
```

## 常见粒子类型

### 火焰粒子（Flame / Soul Flame）

火焰粒子是 Minecraft 中最经典的粒子效果之一，广泛应用于营火、火把、熔炉等方块。

**火焰粒子纹理位置**：`particles.png` 图集中的特定区域

**火焰粒子的行为特点**：
- 向上漂浮运动
- 逐渐变小并淡出
- 受风力影响轻微摆动
- 发光效果（影响光照贴图）

**自定义火焰纹理**：

替换 `particles.png` 中对应区域的火焰纹理，可以改变火焰颜色。例如创建蓝色火焰：

```python
# 使用 Python + Pillow 修改 particles.png 中的火焰纹理
from PIL import Image

# 打开原始 particles.png
img = Image.open("particles.png").convert("RGBA")
pixels = img.load()

# 火焰纹理位于图集的 (32,0) 到 (47,15) 区域
# 将红色通道与蓝色通道交换，创建蓝色火焰效果
for y in range(16):
    for x in range(16):
        px = pixels[32 + x, 0 + y]
        if px[3] > 0:  # 只处理非透明像素
            # 交换 R 和 B 通道
            pixels[32 + x, 0 + y] = (px[2], px[1], px[0], px[3])

img.save("particles_custom.png")
```

### 烟雾粒子（Smoke / Large Smoke）

烟雾粒子用于模拟燃烧产生的烟雾，分为普通烟雾和大型烟雾两种。

**烟雾粒子的特点**：
- 向上漂浮并扩散
- 逐渐变透明
- 灰色调色板
- 大型烟雾尺寸约为普通烟雾的两倍

### 水粒子（Water Drop / Splash）

水相关粒子包括水滴、水花、气泡等多种类型。

**水相关粒子类型**：

| 粒子名称 | 用途 | 特点 |
|----------|------|------|
| `water_drop` | 雨滴落在方块上 | 小型白色点状 |
| `splash` | 玩家入水 | 白色水花飞溅 |
| `bubble` | 水中气泡 | 小型白色圆点向上漂浮 |
| `bubble_pop` | 气泡破裂 | 扩散消失效果 |
| `bubble_column_up` | 气泡柱 | 持续向上运动 |
| `falling_water` | 流水落差 | 从高处下落的水滴 |

### 爆炸粒子（Explosion）

爆炸粒子包含多种变体，用于 TNT 爆炸、苦力怕爆炸、末影水晶爆炸等场景。

**爆炸粒子序列**：

```json
// explosion.json - 爆炸粒子定义
{
  "textures": [
    "minecraft:explosion_0",
    "minecraft:explosion_1",
    "minecraft:explosion_2",
    "minecraft:explosion_3",
    "minecraft:explosion_4",
    "minecraft:explosion_5",
    "minecraft:explosion_6",
    "minecraft:explosion_7"
  ]
}
```

爆炸粒子的特点：
- 快速播放帧动画（约 4 tick/帧）
- 从中心向外扩散
- 逐渐变透明
- 最终消失

### 附魔粒子（Enchant）

附魔粒子是附魔台周围和附魔时出现的神秘光效粒子。

**附魔粒子的特点**：
- 沿附魔台书本螺旋上升
- 多种颜色混合（紫色、蓝色）
- 闪烁效果
- 使用 `enchant` 相关纹理

### 信标粒子（Beacon）

信标激活时产生的光柱粒子效果。

**信标粒子的特点**：
- 垂直向上运动
- 形成光柱效果
- 颜色取决于信标底座材料
- 持续性粒子效果

## 粒子效果修改

### 颜色修改

粒子颜色是资源包层面最容易修改的属性。修改方法包括：

#### 方法一：直接修改纹理颜色

通过图像编辑软件修改粒子纹理的像素颜色：

```python
# Python 脚本：批量调整粒子纹理色调
from PIL import Image
import colorsys

def shift_hue(image_path, hue_shift):
    """调整图像的色相"""
    img = Image.open(image_path).convert("RGBA")
    pixels = img.load()
    width, height = img.size

    for y in range(height):
        for x in range(width):
            r, g, b, a = pixels[x, y]
            if a > 0:  # 只处理非透明像素
                # 转换到 HSV 色彩空间
                h, s, v = colorsys.rgb_to_hsv(r / 255, g / 255, b / 255)
                # 调整色相
                h = (h + hue_shift) % 1.0
                # 转换回 RGB
                r, g, b = colorsys.hsv_to_rgb(h, s, v)
                pixels[x, y] = (int(r * 255), int(g * 255), int(b * 255), a)

    img.save(image_path)

# 将火焰粒子色调偏移 0.5（变成蓝色系）
shift_hue("flame.png", 0.5)
```

#### 方法二：使用着色器影响粒子颜色

对于支持自定义着色器的环境（如 OptiFine / Iris），可以通过着色器修改粒子颜色：

```glsl
// 粒子颜色修改片段着色器示例
#version 150

uniform sampler2D Sampler0;
uniform vec4 ColorModulator;

in vec4 vertexColor;
in vec2 texCoord0;

out vec4 fragColor;

void main() {
    vec4 color = texture(Sampler0, texCoord0) * vertexColor;

    // 将粒子颜色调整为暖色调
    color.r *= 1.2;
    color.g *= 0.9;
    color.b *= 0.7;

    if (color.a < 0.1) discard;

    fragColor = color * ColorModulator;
}
```

### 大小修改

粒子大小在资源包层面的修改能力有限，但可以通过以下方式间接影响：

1. **纹理尺寸调整**：修改纹理本身的实际绘制区域大小
2. **着色器缩放**：在着色器中对粒子顶点进行缩放

```glsl
// 在顶点着色器中缩放粒子
void main() {
    vec4 position = ProjMat * ModelViewMat * vec4(Position, 1.0);

    // 将粒子放大 1.5 倍
    position.xy *= 1.5;

    gl_Position = position;
}
```

### 行为修改

粒子行为（如运动轨迹、重力影响、生命周期）主要由游戏引擎控制，资源包层面的修改有限。但可以通过数据包配合资源包实现部分行为自定义。

### 精灵图集工具

处理 `particles.png` 图集的专用工具：

```python
# particles_atlas_tool.py - particles.png 图集管理工具
from PIL import Image

class ParticlesAtlas:
    ATLAS_SIZE = 128
    CELL_SIZE = 16
    GRID_SIZE = 8  # 128 / 16 = 8x8 网格

    def __init__(self, atlas_path=None):
        if atlas_path:
            self.atlas = Image.open(atlas_path).convert("RGBA")
        else:
            self.atlas = Image.new("RGBA", (self.ATLAS_SIZE, self.ATLAS_SIZE), (0, 0, 0, 0))

    def get_particle(self, row, col):
        """获取指定位置的粒子纹理"""
        x = col * self.CELL_SIZE
        y = row * self.CELL_SIZE
        return self.atlas.crop((x, y, x + self.CELL_SIZE, y + self.CELL_SIZE))

    def set_particle(self, row, col, texture):
        """设置指定位置的粒子纹理"""
        x = col * self.CELL_SIZE
        y = row * self.CELL_SIZE
        self.atlas.paste(texture, (x, y))

    def replace_particle_color(self, row, col, old_color, new_color):
        """替换指定粒子中的特定颜色"""
        particle = self.get_particle(row, col)
        pixels = particle.load()
        for y in range(self.CELL_SIZE):
            for x in range(self.CELL_SIZE):
                if pixels[x, y][:3] == old_color:
                    pixels[x, y] = new_color + (pixels[x, y][3],)
        self.set_particle(row, col, particle)

    def save(self, path):
        """保存图集"""
        self.atlas.save(path)

# 使用示例
atlas = ParticlesAtlas("particles.png")

# 获取火焰粒子（位于第 0 行，第 2 列）
flame = atlas.get_particle(0, 2)
flame.save("extracted_flame.png")

# 替换烟雾粒子颜色（位于第 0 行，第 6 列）
```

## 性能优化

### 粒子数量控制

粒子数量是影响游戏性能的重要因素。资源包开发者应该：

1. **避免过于复杂的粒子纹理**：简单的纹理渲染更快
2. **使用适当的纹理尺寸**：8x8 或 16x16 通常足够
3. **减少纹理帧数**：过多的动画帧会增加内存占用

### 纹理优化

```python
# 粒子纹理优化脚本
from PIL import Image

def optimize_particle_texture(input_path, output_path, max_size=16):
    """优化粒子纹理尺寸"""
    img = Image.open(input_path).convert("RGBA")

    # 如果纹理超过最大尺寸，缩小
    if img.width > max_size or img.height > max_size:
        img = img.resize((max_size, max_size), Image.LANCZOS)

    # 保存时使用优化选项
    img.save(output_path, optimize=True)
    print(f"优化完成: {input_path} -> {output_path}")

def batch_optimize_particles(input_dir, output_dir, max_size=16):
    """批量优化粒子纹理"""
    os.makedirs(output_dir, exist_ok=True)

    for f in os.listdir(input_dir):
        if f.endswith('.png'):
            input_path = os.path.join(input_dir, f)
            output_path = os.path.join(output_dir, f)
            optimize_particle_texture(input_path, output_path, max_size)

# 使用示例
batch_optimize_particles(
    "assets/minecraft/textures/particle/",
    "assets/minecraft/textures/particle_optimized/"
)
```

### 渲染优化建议

| 优化项 | 建议 | 影响 |
|--------|------|------|
| 纹理尺寸 | 使用 8x8 或 16x16 | 减少内存占用 |
| 动画帧数 | 控制在 4-8 帧 | 减少纹理切换 |
| 透明像素 | 尽量减少 | 减少 Alpha 混合计算 |
| 颜色深度 | 使用 8 位调色板 | 减少纹理文件大小 |

```python
# generate_rainbow_flame.py
from PIL import Image
import colorsys

def create_rainbow_flame():
    """创建彩虹渐变火焰纹理"""
    # 打开原始 particles.png
    atlas = Image.open("particles.png").convert("RGBA")
    pixels = atlas.load()

    # 火焰纹理位于 (32,0) 到 (47,15)
    flame_x_start, flame_y_start = 32, 0

    for y in range(16):
        for x in range(16):
            px = pixels[flame_x_start + x, flame_y_start + y]
            if px[3] > 0:
                # 根据 y 坐标计算彩虹色
                hue = (y / 16.0 + x / 32.0) % 1.0
                r, g, b = colorsys.hsv_to_rgb(hue, 0.8, 1.0)

                # 保持原始亮度
                brightness = (px[0] + px[1] + px[2]) / 3 / 255.0
                r = int(r * brightness * 255)
                g = int(g * brightness * 255)
                b = int(b * brightness * 255)

                pixels[flame_x_start + x, flame_y_start + y] = (r, g, b, px[3])

    atlas.save("rainbow_fire/particles.png")
    print("彩虹火焰纹理生成完成")
```

```python
    img = Image.new("RGBA", (size, size), (0, 0, 0, 0))
```

## 常见问题与解决方案

### Q1：替换 particles.png 后粒子显示异常

**原因**：尺寸不匹配或 UV 坐标错位

**解决方案**：
- 确保 particles.png 为 128x128 像素
- 检查每个子纹理是否精确对齐 16x16 网格
- 使用像素完美编辑，避免抗锯齿导致的边缘溢出

### Q2：自定义粒子纹理不显示

**原因**：路径错误或命名不符合规范

**解决方案**：
- 检查纹理文件路径是否正确
- 确保文件名使用小写字母、数字和下划线
- 验证 pack.mcmeta 中的 pack_format 是否正确

### Q3：粒子颜色在游戏中与预期不符

**原因**：游戏的光照系统和颜色混合影响最终显示效果

**解决方案**：
- 在游戏中实际测试，而不是仅在图像编辑器中预览
- 考虑粒子的发光属性对颜色的影响
- 调整纹理亮度以补偿游戏中的颜色混合

### Q4：动画粒子播放不流畅

**原因**：帧数不足或帧时间设置不当

**解决方案**：
- 增加动画帧数（推荐 4-8 帧）
- 确保每帧之间的过渡平滑
- 使用插值算法生成中间帧

### Q5：如何为模组添加兼容的粒子效果

**解决方案**：
- 了解模组使用的粒子类型和纹理路径
- 在资源包中为模组命名空间创建对应的粒子纹理
- 测试与模组的兼容性
