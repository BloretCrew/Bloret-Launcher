## 模组兼容的重要性

### 为什么需要模组兼容

Minecraft 的模组生态系统极为庞大，拥有数千个不同类型的模组。玩家在使用资源包的同时，通常会安装多个模组来增强游戏体验。如果你的资源包与常见模组不兼容，将会导致：

1. **视觉不一致**：模组添加的方块/物品使用默认纹理，与资源包风格格格不入
2. **功能缺失**：某些依赖特定资源包格式的功能（如 OptiFine 的 CTM、CEM）无法正常工作
3. **玩家流失**：玩家可能会因为兼容性问题而放弃使用你的资源包

### 兼容性问题的常见表现

```
兼容性问题分类：

1. 纹理缺失
   - 模组方块显示紫黑色棋盘格
   - 物品图标显示错误或缺失

2. 模型错误
   - 模组物品模型变形或不可见
   - 方块状态显示异常

3. 功能失效
   - OptiFine 连接纹理不工作
   - 自定义实体模型（CEM）失效

4. 声音异常
   - 模组声音播放失败
   - 音效与资源包风格不匹配
```

### 兼容性开发的目标

| 目标 | 描述 | 优先级 |
|------|------|--------|
| 基础兼容 | 确保资源包不与模组冲突 | 高 |
| 视觉一致 | 模组内容与资源包风格匹配 | 中 |
| 功能增强 | 利用模组 API 扩展资源包功能 | 低 |

## 命名空间机制

### 理解命名空间

Minecraft 使用命名空间（Namespace）来组织和区分不同来源的资源。命名空间是资源标识符的一部分，格式为 `namespace:path`。

#### 默认命名空间

```
minecraft:       # Minecraft 原版资源
  ├── textures/block/stone.png
  ├── models/block/stone.json
  └── sounds/ambient/cave.ogg

mypack:          # 你的资源包命名空间
  ├── textures/block/custom_stone.png
  ├── models/block/custom_stone.json
  └── sounds/custom/special.ogg
```

#### 模组命名空间

每个模组通常有自己的命名空间：

```
modid:           # 模组标识符作为命名空间
  ├── textures/block/mod_block.png
  ├── models/block/mod_block.json
  └── sounds/mod/mod_sound.ogg

# 常见模组命名空间示例
create:          # Create 模组
botania:         # Botania 模组
ae2:             # Applied Energistics 2
mekanism:        # Mekanism 模组
tconstruct:      # Tinkers' Construct
```

### 命名空间与资源包

在资源包中，你可以为任何命名空间添加资源：

```
my_resource_pack/
├── pack.mcmeta
└── assets/
    ├── minecraft/           # 修改原版资源
    │   ├── textures/
    │   │   └── block/
    │   │       └── stone.png
    │   └── models/
    │       └── block/
    │           └── stone.json
    ├── create/              # 为 Create 模组添加资源
    │   └── textures/
    │       └── block/
    │           └── cogwheel.png
    └── mypack/              # 自定义命名空间
        └── textures/
            └── block/
                └── custom_block.png
```

### 命名空间解析规则

```python
# 命名空间解析示例
def resolve_resource_location(resource_id, base_namespace="minecraft"):
    """
    解析资源标识符

    Args:
        resource_id: 资源标识符，如 "stone" 或 "create:cogwheel"
        base_namespace: 默认命名空间

    Returns:
        (namespace, path) 元组
    """
    if ':' in resource_id:
        namespace, path = resource_id.split(':', 1)
    else:
        namespace = base_namespace
        path = resource_id

    return namespace, path

# 示例
print(resolve_resource_location("stone"))
# 输出: ('minecraft', 'stone')

print(resolve_resource_location("create:cogwheel"))
# 输出: ('create', 'cogwheel')

print(resolve_resource_location("mypack:custom_block"))
# 输出: ('mypack', 'custom_block')
```

## 常见模组类型

### Forge 和 Fabric

Forge 和 Fabric 是 Minecraft 最主流的两个模组加载器，它们对资源包的支持方式略有不同。

#### Forge 模组资源结构

```
forge_mod.jar 内部结构：
├── META-INF/
│   └── mods.toml
├── assets/
│   └── modid/
│       ├── textures/
│       ├── models/
│       ├── sounds.json
│       └── sounds/
└── data/
    └── modid/
        └── ...
```

#### Fabric 模组资源结构

```
fabric_mod.jar 内部结构：
├── fabric.mod.json
├── assets/
│   └── modid/
│       ├── textures/
│       ├── models/
│       ├── sounds.json
│       └── sounds/
└── data/
    └── modid/
        └── ...
```

#### 兼容性差异

| 特性 | Forge | Fabric |
|------|-------|--------|
| 资源加载 | 自定义 ResourcePack 系统 | 标准 Minecraft 资源系统 |
| 命名空间 | 标准命名空间 | 标准命名空间 |
| 模型覆盖 | 支持 | 支持 |
| 纹理覆盖 | 支持 | 支持 |
| 事件系统 | 更复杂 | 更简洁 |

│   │   ├── entity/

### Sodium 和 Iris

Sodium 是 Fabric 的性能优化模组，Iris 是 Sodium 的着色器兼容层。

```
Sodium/Iris 兼容性特点：

1. Sodium 使用自己的渲染管线
   - 某些 OptiFine 特性可能不支持
   - 基本纹理和模型兼容性良好

2. Iris 支持 OptiFine 着色器格式
   - 大部分 OptiFine 着色器可以工作
   - 某些高级特性可能有差异

3. 资源包兼容性
   - 标准 Minecraft 资源包完全兼容
   - OptiFine 专属特性可能需要额外适配
```

### JEI 和 REI

JEI（Just Enough Items）和 REI（Roughly Enough Items）是物品查看器模组，它们对资源包的兼容性主要体现在 GUI 方面。

```
JEI/REI 兼容性要点：

1. 物品渲染
   - 使用标准 Minecraft 物品渲染系统
   - 资源包的物品纹理自动兼容

2. GUI 纹理
   - JEI/REI 有自己的 GUI 纹理
   - 可以通过资源包自定义

3. 物品描述
   - 使用语言文件系统
   - 支持资源包的自定义翻译
```

{
  "texture": "minecraft:textures/entity/zombie/zombie.png",
  "textureSize": [64, 64],
  "models": [
    {
      "part": "head",
      "id": "head",
      "invertAxis": "xy",
      "translate": [0, -24, 0],
      "submodel": {
        "id": "hat",
        "invertAxis": "xy",
        "translate": [0, -24, 0],

          {
            "coordinates": [-4, -8, -4, 8, 8, 8],

      "part": "body",
      "id": "body",

      "translate": [0, -24, 0],

### CIT - 自定义物品纹理

CIT（Custom Item Textures）允许根据物品属性（名称、附魔、NBT 数据）显示不同的纹理。

#### CIT 属性文件格式

```properties
# assets/minecraft/optifine/cit/items/custom_diamond_sword.properties

# 基础属性
type=item
items=minecraft:diamond_sword
texture=custom_diamond_sword.png

# 匹配条件
nbt.display.Name=ipattern:*火焰之剑*
nbt.enchantments.minecraft:fire_aspect=1

# 纹理模型（可选）
model=custom_diamond_sword.json
```

#### CIT 匹配条件

| 条件 | 语法 | 示例 |
|------|------|------|
| 精确匹配 | `nbt.tag=value` | `nbt.display.Name=Special Sword` |
| 模式匹配 | `nbt.tag=pattern:*text*` | `nbt.display.Name=pattern:*剑*` |
| 不区分大小写 | `nbt.tag=ipattern:*text*` | `nbt.display.Name=ipattern:*sword*` |
| 正则匹配 | `nbt.tag=regex:pattern` | `nbt.display.Name=regex:.*剑.*` |
| 存在检查 | `nbt.tag` | `nbt.display.Lore` |

#### CIT 示例：附魔剑变体

```properties
# 附魔钻石剑 - 火焰属性
type=item
items=minecraft:diamond_sword
texture=diamond_sword_fire.png
nbt.enchantments.minecraft:fire_aspect
```

```properties
# 附魔钻石剑 - 锋利属性
type=item
items=minecraft:diamond_sword
texture=diamond_sword_sharp.png
nbt.enchantments.minecraft:sharpness
```

### CTM - 连接纹理

CTM（Connected Textures）是最常用的 OptiFine 功能之一，允许相邻的同类方块纹理自动连接。

#### CTM 属性文件格式

```properties
# assets/minecraft/optifine/ctm/glass/glass.properties

# 基础设置
method=ctm
tiles=0-46
connect=block
matchBlocks=minecraft:glass
```

#### CTM 连接方法

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| `ctm` | 标准连接纹理（47 种变体） | 玻璃、冰等 |
| `ctm_compact` | 紧凑连接纹理（13 种变体） | 简化连接 |
| `random` | 随机纹理选择 | 石头、草地 |
| `repeat` | 重复纹理 | 大型表面 |
| `vertical` | 垂直连接 | 藤蔓、柱子 |
| `horizontal` | 水平连接 | 栅栏 |
| `top` | 顶部连接 | 草地顶部 |
| `fixed` | 固定纹理 | 特定方向 |

#### CTM 完整示例

```properties
# 玻璃连接纹理配置
method=ctm
tiles=0-46
connect=block
matchBlocks=minecraft:glass
faces=solid
biomeSensitive=false
```

对应的纹理图片需要是 47 个 16x16 纹理的条带图（sprite sheet），总尺寸为 752x16 像素。

# 分析模组资源结构
def analyze_mod_resources(mod_jar_path):
    """分析模组 JAR 文件中的资源结构"""
    import zipfile

    resources = {
        'textures': [],
        'models': [],
        'sounds': []
    }

    with zipfile.ZipFile(mod_jar_path, 'r') as zip_ref:
        for file_info in zip_ref.infolist():
            filename = file_info.filename

            if filename.startswith('assets/'):
                if '/textures/' in filename and filename.endswith('.png'):
                    resources['textures'].append(filename)
                elif '/models/' in filename and filename.endswith('.json'):
                    resources['models'].append(filename)
                elif '/sounds/' in filename and filename.endswith('.ogg'):
                    resources['sounds'].append(filename)

    return resources

# 使用示例
resources = analyze_mod_resources("create-mod.jar")
print("纹理文件:", len(resources['textures']))
print("模型文件:", len(resources['models']))
print("声音文件:", len(resources['sounds']))

#### 步骤 3：适配纹理风格

```python
# 纹理风格适配工具
from PIL import Image
import colorsys

def match_texture_style(source_path, target_style_path, output_path):
    """
    将源纹理的风格匹配到目标风格

    Args:
        source_path: 源纹理路径（模组纹理）
        target_style_path: 目标风格纹理路径（资源包风格参考）
        output_path: 输出路径
    """
    source = Image.open(source_path).convert("RGBA")
    target = Image.open(target_style_path).convert("RGBA")

    # 分析目标风格的颜色特征
    target_colors = analyze_texture_colors(target)
    source_colors = analyze_texture_colors(source)

    # 应用颜色转换
    result = apply_color_transform(source, source_colors, target_colors)
    result.save(output_path)

def analyze_texture_colors(image):
    """分析纹理的颜色特征"""
    pixels = list(image.getdata())
    valid_pixels = [p for p in pixels if p[3] > 0]

    if not valid_pixels:
        return None

    # 计算平均颜色
    avg_r = sum(p[0] for p in valid_pixels) / len(valid_pixels)
    avg_g = sum(p[1] for p in valid_pixels) / len(valid_pixels)
    avg_b = sum(p[2] for p in valid_pixels) / len(valid_pixels)

    return (avg_r, avg_g, avg_b)

def apply_color_transform(image, source_colors, target_colors):
    """应用颜色转换"""
    result = image.copy()
    pixels = result.load()

    for y in range(image.height):
        for x in range(image.width):
            r, g, b, a = pixels[x, y]
            if a > 0:
                # 简单的颜色偏移
                r = min(255, max(0, int(r + target_colors[0] - source_colors[0])))
                g = min(255, max(0, int(g + target_colors[1] - source_colors[1])))
                b = min(255, max(0, int(b + target_colors[2] - source_colors[2])))
                pixels[x, y] = (r, g, b, a)

    return result
```

### 声音风格匹配

确保自定义声音与资源包的整体风格一致：

```python
# 声音风格分析工具
import subprocess
import json

def analyze_audio_characteristics(audio_path):
    """分析音频特征"""
    # 使用 ffprobe 获取音频信息
    cmd = ['ffprobe', '-v', 'quiet', '-print_format', 'json',
           '-show_format', '-show_streams', audio_path]

    result = subprocess.run(cmd, capture_output=True, text=True)
    info = json.loads(result.stdout)

    if 'streams' in info and len(info['streams']) > 0:
        stream = info['streams'][0]
        return {
            'sample_rate': int(stream.get('sample_rate', 0)),
            'channels': int(stream.get('channels', 0)),
            'duration': float(info['format'].get('duration', 0)),
            'bit_rate': int(info['format'].get('bit_rate', 0))
        }

    return None

# 使用示例
chars = analyze_audio_characteristics("sounds/block/cogwheel_rotate.ogg")
if chars:
    print(f"采样率: {chars['sample_rate']} Hz")
    print(f"声道数: {chars['channels']}")
    print(f"时长: {chars['duration']:.2f} 秒")
```

# mod_compatibility_tester.py
import os
import json

class ModCompatibilityTester:
    def __init__(self, pack_path):
        self.pack_path = pack_path
        self.results = []

    def check_namespace_coverage(self, mod_namespaces):
        """检查命名空间覆盖情况"""
        assets_dir = os.path.join(self.pack_path, 'assets')

        for namespace in mod_namespaces:
            ns_path = os.path.join(assets_dir, namespace)
            exists = os.path.exists(ns_path)

            if exists:
                texture_count = sum(
                    1 for root, dirs, files in os.walk(ns_path)
                    for f in files if f.endswith('.png')
                )
                model_count = sum(
                    1 for root, dirs, files in os.walk(ns_path)
                    for f in files if f.endswith('.json')
                )

                self.results.append({
                    'test': f'命名空间 {namespace}',
                    'status': 'PASS',
                    'details': f'{texture_count} 纹理, {model_count} 模型'
                })
            else:
                self.results.append({
                    'test': f'命名空间 {namespace}',
                    'status': 'INFO',
                    'details': '未包含（可选）'
                })

    def check_optifine_support(self):
        """检查 OptiFine 扩展支持"""
        optifine_dir = os.path.join(self.pack_path, 'assets', 'minecraft', 'optifine')

        features = {
            'cit': '自定义物品纹理',

            'random': '随机生物纹理',
            'bettergrass': '更好的草地',

        }

        for feature, name in features.items():
            feature_path = os.path.join(optifine_dir, feature)
            exists = os.path.exists(feature_path)

            self.results.append({
                'test': f'OptiFine {name}',
                'status': 'PASS' if exists else 'SKIP',
                'details': '已支持' if exists else '未包含'
            })

    def generate_report(self):
        """生成兼容性报告"""
        print("\n" + "=" * 60)

        print("=" * 60)

        for r in self.results:

                'PASS': '✓',
                'FAIL': '✗',
                'SKIP': '-',
                'INFO': 'i'
            }.get(r['status'], '?')

            print(f"{status_icon} {r['test']}: {r['status']}")
            if 'details' in r:
                print(f"  {r['details']}")

# 使用示例

# 科技模组纹理风格适配
from PIL import Image, ImageFilter

def create_tech_style_texture(source_path, output_path):
    """创建科技风格纹理"""
    img = Image.open(source_path).convert("RGBA")

    # 1. 增加金属感 - 提高对比度
    from PIL import ImageEnhance
    enhancer = ImageEnhance.Contrast(img)
    img = enhancer.enhance(1.3)

    # 2. 添加轻微的高斯模糊模拟金属光泽
    # 只对亮度通道模糊，保持颜色细节
    img_rgb = img.convert("RGB")
    img_blurred = img_rgb.filter(ImageFilter.GaussianBlur(radius=1))

    # 混合原图和模糊图
    from PIL import ImageChops
    blended = ImageChops.blend(img_rgb, img_blurred, alpha=0.3)

    # 3. 转换回 RGBA
    result = blended.convert("RGBA")
    if img.mode == "RGBA":
        result.putalpha(img.split()[3])

    result.save(output_path)

# 使用示例

                          "assets/mekanism/textures/block/steel_casing.png")

### Q1：模组方块显示紫黑色棋盘格

**原因**：资源包中缺少模组方块的纹理文件

**解决方案**：

```python
# 检查缺失的模组纹理
def find_missing_mod_textures(pack_path, mod_namespaces):
    """查找缺失的模组纹理"""
    missing = []

    for namespace in mod_namespaces:
        # 检查资源包中是否存在该命名空间
        ns_path = os.path.join(pack_path, 'assets', namespace)
        if not os.path.exists(ns_path):
            missing.append(f"缺少命名空间: {namespace}")
            continue

        # 检查是否有纹理目录
        texture_path = os.path.join(ns_path, 'textures')
        if not os.path.exists(texture_path):
            missing.append(f"缺少纹理目录: {namespace}/textures/")

    return missing
```

### Q3：资源包与多个模组冲突

**原因**：不同模组对同一资源有不同的命名或格式要求

**解决方案**：

```python
# 检查资源冲突
def check_resource_conflicts(pack_path):
    """检查资源包中的潜在冲突"""
    conflicts = []

    # 检查是否有重复的资源标识符
    resource_ids = {}
    for root, dirs, files in os.walk(pack_path):
        for f in files:
            if f.endswith('.json') or f.endswith('.png'):
                # 构建资源标识符
                rel_path = os.path.relpath(os.path.join(root, f), pack_path)
                resource_id = rel_path.replace(os.sep, '/')

                if resource_id in resource_ids:
                    conflicts.append({
                        'resource': resource_id,
                        'locations': [resource_ids[resource_id], os.path.join(root, f)]
                    })
                else:
                    resource_ids[resource_id] = os.path.join(root, f)

    return conflicts
```
