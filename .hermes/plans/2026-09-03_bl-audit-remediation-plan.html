明确排除项

  • 不处理、不读取、不删除、不轮换 sign/root.pvk。
  • 不修改签名证书文件、生产发布配置或真实发布链。
  • 不得因其他改动把该密钥或任何凭据带入新提交。

修复范围

  1. Passport/OAuth：移除客户端硬编码 app secret；采用 PKCE/短期挑战或现有安全服务端流程；禁止远程 HTTPS 降级到 HTTP；缺少/拒绝/过期 code 必须显示失败，不得伪装成功。
  2. 路径与进程：统一版本目录解析，拒绝绝对路径、..、符号链接和越界；完善启动/终止的进程树清理和 Windows Job Object 边界。
  3. OOBE：修复 Passport 稳定 ID 导航；Java 下载失败/取消/超时显示可恢复错误；账号同步使用真实 started/succeeded/failed/cancelled 信号，不用固定计时器；BBBS 失败显示可见错误并可重试。
  4. 插件权限：高风险权限默认拒绝，未知权限 fail-closed；明确插件是信任代码还是隔离子进程，不把普通权限提示冒充沙箱。
  5. 下载和发布：EasyTier、AppImage 等可执行下载固定版本并校验 SHA-256/签名；release 构建缺证书必须失败，fork/PR 才可跳过；不处理被明确排除的证书私钥本体。
  6. 生命周期与并发：导入 web 模块不启动监听；Web 服务显式 start/stop；running_instances、launch_status、配置 read-modify-write、recent_runs 使用统一锁/原子替换；请求增加 timeout、取消和错误状态。
  7. UI/体验：PluginStore 缺字段安全归一化；Mods/PluginStore/Statistics/Tools 增加加载、空、错误、重试状态；修复自定义启动项重命名或移除误导入口；补 QML 路由可达性、主题、国际化、窄屏和可访问性。
  8. 架构维护：新逻辑优先 modules/services/；legacy 入口统一调用服务层；补文档、schema、部署说明、测试发现和运行产物治理。
