## 问题

语言列表下拉框显示 `QQmIDMListAccessorData(...)` 而不是语言名称（如"简体中文"、"English"）

## 根本原因

RinUI 的 `ComboBox.qml` 没有将 `textRole` 属性传递给内部的 `ContextMenu`，导致下拉菜单无法正确获取显示文本。

## 修复方案

修改 `g:\Work\git\Bloret-Launcher\RinUI\components\BasicInput\ComboBox.qml`，在 `ContextMenu` 中添加 `textRole` 绑定：

```qml
popup: ContextMenu {
    id: menu
    width: root.width
    model: root.model
    currentIndex: root.currentIndex
    textRole: root.textRole  // 添加这一行
    ...
}
```
