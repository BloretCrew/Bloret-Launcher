## 修复计划

### 1. 修复界面布局问题
当前界面可能存在以下问题：
- 启动卡片没有固定在底部
- 布局宽度/高度不正确

修复方案：检查并修复 Home.qml 的布局结构

### 2. 添加核心管理功能

核心管理是一个复杂的功能，包含多个页面：
- 基本信息
- 服务器
- 资源包
- Mod
- 高级设置

由于这需要大量工作，采用分步方案：

**方案 A（推荐）：创建 Python 端核心管理对话框**
1. 在 Python 端使用 PySide6 创建核心管理对话框（参考老程序）
2. 在 Backend 中添加 `showCoreManager(versionName)` 方法
3. 在 QML 中调用该方法显示对话框

**方案 B：创建简化版 QML 组件**
1. 创建一个简化版的 QML 核心管理对话框
2. 只包含基本信息编辑功能
3. 其他功能后续逐步添加
