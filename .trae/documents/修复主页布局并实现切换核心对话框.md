## 修复计划

### 1. 修复 Home.qml 布局问题
当前问题：
- 使用 `Item` 作为根元素可能导致布局问题
- 需要确保启动卡片固定在底部

修复方案：
- 调整布局结构，确保 ScrollView 和启动卡片的正确分层

### 2. 创建 LaunchSelectorDialog.qml
创建启动项选择对话框组件：
- 使用 RinUI 的 Dialog 组件
- 显示所有启动项列表（Minecraft 版本 + 自定义项目）
- 每个项目显示图标、名称和选择按钮
- 支持右键菜单：
  - Minecraft 项目：启动、核心管理、打开文件位置
  - 自定义项目：启动、更名、删除

### 3. 在 Backend 中添加相关方法
- `getLaunchItems()` - 已存在，返回启动项列表
- `selectLaunchItem(name)` - 选择启动项
- `manageCore(versionName)` - 打开核心管理
- `openVersionFolder(versionName)` - 打开版本文件夹
- `renameCustomItem(oldName, newName)` - 重命名自定义项目
- `deleteCustomItem(name)` - 删除自定义项目

### 4. 修改 Home.qml 的切换核心按钮
- 点击时显示 LaunchSelectorDialog 对话框
- 选择后更新当前版本显示
