## 问题

`QUiLoader.load()` 在 PySide6 中不接受 `TextIOWrapper`（`open()` 返回的文件对象）。

错误信息显示支持的签名：
- `load(device: QIODevice, parentWidget)` 
- `load(arg__1: str | bytes | os.PathLike[str], parentWidget)`

## 修复方案

修改 `modules/install.py` 中的 `load_ui_file()` 函数，直接传递文件路径字符串给 `loader.load()`，而不是打开文件：

```python
def load_ui_file(ui_file_path):
    try:
        loader = QUiLoader()
        if not os.path.isabs(ui_file_path):
            script_dir = Path(__file__).parent.parent.absolute()
            ui_file_path = os.path.join(script_dir, ui_file_path)
        
        if not os.path.exists(ui_file_path):
            log(f"UI 文件不存在: {ui_file_path}", logging.WARNING)
            return None
        
        # 直接传递文件路径，而不是打开文件
        ui = loader.load(ui_file_path, None)
        return ui
    except Exception as e:
        log(f"加载 UI 文件失败 {ui_file_path}: {e}", logging.ERROR)
        return None
```
