## 方案：使用 RinUI Dialog 创建下载对话框

### 1. 创建 QML 下载对话框组件
创建 `qml/components/DownloadDialog.qml`，使用 RinUI 的 Dialog 组件，包含：
- 下载进度条
- 下载状态文本
- 暂停/恢复按钮
- 取消按钮

### 2. 修改 main.qml
在主窗口中添加 DownloadDialog 实例

### 3. 修改 Backend 类
- 添加 `showDownloadDialog` 信号
- 添加 `updateDownloadProgress` 信号
- 添加 `closeDownloadDialog` 信号
- 添加下载进度更新方法

### 4. 修改 install.py
- 移除 PyQt 对话框相关代码
- 使用信号机制通知 QML 更新进度
- 通过 Backend 发射信号来控制对话框

### 5. 连接信号与对话框
在 QML 中连接 Backend 信号到对话框的显示/隐藏/更新
