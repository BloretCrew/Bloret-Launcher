## 问题

`DownloadDialog` 组件在 `qml/components/` 目录下，但 `main.qml` 没有导入这个目录，导致 QML 无法找到该组件。

## 解决方案

在 `main.qml` 中添加 import 语句导入 `components` 目录：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import QtQuick.Layouts 2.15
import RinUI
import "components"  // 添加这行
```

这样 QML 就能找到 `components/DownloadDialog.qml` 组件了。
