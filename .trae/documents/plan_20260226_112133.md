## 问题

QML 中的 `qsTr()` 无法使用项目的 JSON 翻译文件，导致界面翻译不生效。

## 解决方案

在 Backend 类中添加 QML 可用的翻译功能：

### 1. 添加翻译方法和信号 (Bloret-Launcher.py)

在 `Backend` 类中添加：
- `languageChanged` 信号：通知 QML 语言已更改，需要刷新界面
- `tr(key)` 方法：让 QML 可以调用 Python 的翻译函数

### 2. 修改 setLanguage 方法

在语言更改后发射 `languageChanged` 信号，通知 QML 刷新界面。

### 3. QML 中使用 Backend.tr() 替代 qsTr()

将 QML 中的 `qsTr("文本")` 替换为 `Backend ? Backend.tr("文本") : "文本"`

这样：
- 翻译数据从项目的 JSON 文件获取
- 语言切换后界面会自动刷新
- 保持与现有翻译系统的一致性
